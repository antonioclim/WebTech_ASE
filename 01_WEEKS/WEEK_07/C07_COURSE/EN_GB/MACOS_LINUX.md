# C07: MACOS/LINUX route

Extract the complete course and open its actual EN_GB folder in VS Code. Substitute your extracted course path for the example below.

```text
cd "$HOME/Downloads/C07_PUBLIC"
node tools/tw-kit.mjs env
node tools/tw-kit.mjs examples
```

These are platform instructions, not a claim of native execution on that platform. Follow [RUN_EXAMPLES](RUN_EXAMPLES.md), [the course guide](guide.html) and the shared capability policy. No npm installation is requested for the four neutral examples. Retain ENV_BLOCKED or unknown cleanup honestly.
