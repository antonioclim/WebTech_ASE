## Classes of evidence

SOURCE_REASONING is an identified passage or code argument. SOURCE_LINKED_MODEL/MODULE_MODEL executes substitutes, not Sequelize. ACTUAL_ORM_SQLITE requires the supplied ORM and native driver. LOCAL_HTTP requires a real request but does not independently authenticate the server implementation. REAL_BROWSER is separate from DOM stand-ins or static layout projections. Never relabel one as another.
