# S07 local tooling — source and execution boundaries

Open `../OPEN.html` for the guide. Run `node tools/cli.mjs help` from the student kit root for exact commands. No tool installs dependencies or uses a project network service.

`verify` checks a fresh clean extracted package before edits or dependency preparation. Expected learner edits and node_modules make that whole-package check fail later. `boundary p02` then checks the supplied project contract while permitting only the mandatory target; a changed target hash is recorded. The contract parser rejects linked metadata and inconsistent role, route or target permissions before accepting a boundary. Observer patches restore original own descriptors or remove temporary own properties over inherited methods. Rejected values remain rejected even when JavaScript throws undefined, null, false, zero or an empty string. Neither check authenticates observations or establishes semantic correctness. Literal-path checks do not remove filesystem race risks. Protect the original clean package and PACKAGE_ID as provenance.

`preflight p02` reads source boundary, Node/npm measurements and project-local direct dependency metadata. It measures npm with the locally found npm-cli.js, the current Node executable and `--version`, under a five-second direct-child bound. Its JSON preserves the actual command, stderr and measurement faults. It imports no canonical application, helper, test or native driver. The runtime target is Node v24.21.0/npm 11.19.0. Linked project package/lock metadata and linked or nonlocal direct dependency metadata are rejected before their JSON is read. Its ready flag is source/resolution/runtime readiness only, with an explicit qualification label. The full dependency graph and publisher provenance remain separate questions.

`synthetic` imports only newly authored built-in-module tools and emits SYNTHETIC_PRACTICE. It contrasts a snapshot toy's partial writes, restoration and option traces. It is not SQLite rollback, P02 completion or permitted final evidence substitution. `node --test tools/supplemental.test.mjs` tests these newly authored tools using synthetic data and owned listeners. It never imports the archived canonical code.

The explicit native, serve, observe and test routes require the exact runtime, a green protected boundary and project-local dependencies. They can load or run canonical code only when chosen in the separately prepared genuine environment. Such routes are supplied for later use and were not executed in candidate production. Do not use direct npm start to infer a listener: protected server entry guards have a Windows/URI limitation.

Serve owns loopback HTTP and its newly created volatile database. It prints the actual port0 URL. Ctrl+C requests closure. STOPPED means the adapter observed closure of its owned resources. Timeout, signal force or kill means cleanup is unknown. The child environment removes case variants of NODE_OPTIONS, NODE_PATH and NODE_TEST_CONTEXT. The bounded child controller limits only the direct child and its captured output; it is not a general sandbox or descendant containment system.

Observe P02 records E01, E02_SERVICE/E05, E02_HTTP, E03_CALLBACK, E03_AUDIT and E04 cases with fresh scenario identity and source expectations separated from observations. Recovery is on the same scenario instance. Its five-operation witness requires exactly the five named calls in order, one shared non-null managed identity and callback identity. This option trace supplements the inherited four-method spy; it is not a complete SQL graph or concurrent isolation proof.
