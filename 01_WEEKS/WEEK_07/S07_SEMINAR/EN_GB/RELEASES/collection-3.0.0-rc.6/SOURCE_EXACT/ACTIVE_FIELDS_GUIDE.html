S07 active fields and evidence guide

P02 Transactional Booking full implementation plus resource/transaction ADR; full P01/P03 optional.

The compact form initially shows the class/core fields. Open the later/final view for all required independent work, final evidence and declarations. Optional work stays optional. Hiding a field does not remove it, change its import ID or excuse an unmet required gate. Print review includes the complete record.

Record each witness once

Use a stable evidence ID for each case and retain: prediction before action; exact action or source; expected result; observed result; mechanism; limitation; locator. Keep actual excerpts in one place. Summary fields cite the evidence ID and add the particular comparison or decision they ask for, rather than repeat the same transcript.

Identity is one record. Fixed seminar/version labels are metadata, not observations. Package ID, real date, environment and access are never inferred from a required version. Baseline, objective and regression outcomes remain distinct; source/model/actual classes remain explicit.
