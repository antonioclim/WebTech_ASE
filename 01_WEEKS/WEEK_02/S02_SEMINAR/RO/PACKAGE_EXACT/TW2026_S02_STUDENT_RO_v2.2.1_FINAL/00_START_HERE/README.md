# Pachet student — Seminarul 2 v2.1

Nucleul canonic este U04-P01 Responsive Card/Grid Reconstruction. Modificaţi numai `01_PROIECT/RESPONSIVE_CARD_GRID_CANONIC/public/styles.css`.

## Pornire

1. Extrageţi complet arhiva.
2. Rulaţi `VERIFICA_PACHET_STUDENT.cmd`.
3. Continuaţi numai după `VERDICT: PASS_PACKAGE_INTEGRITY_EXACT_SET`.
4. Rulaţi `VERIFICA_STAREA_INITIALA.cmd`: objective trebuie să eşueze numai prin assertions.
5. Rulaţi `START_PROIECT.cmd`. Dacă Node.js v24.21.0 + npm 11.19.0 lipseşte, se deschide laboratorul offline.

## Extensie opţională

După nucleul de 60 de minute puteţi deschide `02_LABORATOR_OFFLINE/MUZEUL_CSS_AL_IDEILOR_PROASTE_v2.1_RO.html`. Muzeul este un obiect derivat şi nu modifică proiectul canonic.

## Predarea individuală în Moodle

După experimentele 320/768/1280, conţinut lung, focus şi reduced motion, completaţi formularul din `06_MOODLE_SUBMISSION`, exportaţi PDF-ul şi trimiteţi-l individual.
