S02: observe the actual card fixture in your browser

These finite checks read rendered boxes and computed styles from your own served fixture. A PASS applies only to the listed observations at the selected width. It is not a grade, full project acceptance, visual inspection, proof of keyboard access or proof of reduced-motion behaviour. No student answers or observations are prefilled.

Run the owned classroom server

  1. From the extracted S02 package root, run node CLASSROOM_RC6/kit.mjs serve after the selected runtime capability check has permitted this operation; a version difference alone is not a blocker.
  2. Keep that terminal open. Append /browser-checks.html to its actual READY http://127.0.0.1:PORT address and open it in your browser.
  3. After editing CLASSROOM_RC6/targets/styles.css, select each required width and rerun. Copy your actual results into the current evidence form, alongside your own observations. Stop only this owned listener with Ctrl+C and wait for STOPPED_OWNED_LISTENER.

The unchanged assignment requires 320, 768 and 1280 CSS-pixel measurements. Record browser version, native zoom menu value and the initial browser font setting separately; this inspector cannot reliably infer those settings from device pixel ratio. The root computed font reported below is a page value, not proof of the browser’s initial font or zoom. Rem conditions are measured with matchMedia rather than inferred from body font-size. The optional 390 and 900 widths add observations. Parent-page width does not set subject width: the iframe has the selected CSS-pixel viewport. Its preview scrolls inside the bordered container on small screens.

Finite automatic observations

Visibility here means a nonzero rendered box with visible ancestor styles; occlusion and visual legibility are not certified. The check uses the protected fixture's four cards. It rejects hidden/clip overflow and ellipsis on the fixture's content nodes and checks that its text and links retain visible rendered boxes. The long identifier is also compared with the protected fixture text; you still need to read its full rendered content and check the indicator yourself. Other visual concealment and occlusion still require inspection.

Manual P03 observations — not automated

Use Tab and Shift+Tab on the actual fixture, inspect the visible indicator, then emulate reduced motion in your browser and inspect the computed transition. Enter only your own observation. These records default to NOT_EXECUTED and never change the automatic finite verdict. They remain when you change widths or reload the fixture: record the actual viewport in your notes and revise them after CSS edits. Browser/version, viewport, relevant values and an actual evidence excerpt are needed for your evidence form.
