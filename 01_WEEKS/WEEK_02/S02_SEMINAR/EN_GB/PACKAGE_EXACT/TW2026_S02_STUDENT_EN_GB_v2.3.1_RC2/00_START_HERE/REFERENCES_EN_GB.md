# S02 primary reference register

Read the named part when you need to check a mechanism. These links explain the web platform; they do not prescribe this exercise's exact 1/2/4 columns, breakpoints or 72rem cap.

| Reference | Targeted reading | Use in this seminar |
| --- | --- | --- |
| [CSS Grid Layout Level 1](https://www.w3.org/TR/css-grid-1/) | Grid containers, automatic minimum size of grid items, track sizing | Collection tracks and intrinsic sizing; Candidate Recommendation Draft |
| [CSS Flexible Box Layout Level 1](https://www.w3.org/TR/css-flexbox-1/) | Flex containers, automatic minimum size, alignment and auto margins | Header and card relationships; consult the status shown by the specification |
| [Media Queries Level 5](https://www.w3.org/TR/mediaqueries-5/) | `prefers-reduced-motion` | Preference detection; consult the status shown by the specification |
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | 1.4.4 Resize Text, 1.4.10 Reflow, 2.1.1 Keyboard, 2.4.7 Focus Visible | Reasons for manual keyboard and native zoom checks; W3C Recommendation |

An outline-width measurement is bounded focus-style evidence. It does not establish every WCAG requirement, sufficient contrast, every keyboard action, or conformance of the whole page.
