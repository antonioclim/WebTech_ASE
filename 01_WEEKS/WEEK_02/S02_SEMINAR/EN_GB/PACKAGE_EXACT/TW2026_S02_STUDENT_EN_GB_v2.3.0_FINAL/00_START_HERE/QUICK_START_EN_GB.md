# Quick start with recovery gates

1. Extract the ZIP. Confirm the root contains `00_START_HERE`, `02_PROJECTS`, `90_AUDIT` and the launchers.
2. Run `VERIFY_PACKAGE`. STOP if the exact-set verdict is not PASS.
3. Open the interactive guide. Choose your browser in its toolbar.
4. Run `CHECK_ENVIRONMENT`. Record the actual Node.js, npm and browser versions.
5. Write both predictions before execution.
6. Run `VERIFY_INITIAL_STATE`. Required: baseline 1 pass, objective exactly 3 assertion failures and regression 2 passes.
7. Edit only `02_PROJECTS/RESPONSIVE_CARD_GRID/public/styles.css`.
8. Run `START_PROJECT`. The address must begin with `http://127.0.0.1:`.
9. Test 320, 768 and 1280 CSS px, long content, keyboard focus and reduced motion.
10. Audit one Gemini claim independently.
11. Run `VERIFY_WORK_RESULT`.
12. Complete the form, save one PDF and inspect every page.
13. Submit the PDF and STOP until Moodle no longer reports Draft.
