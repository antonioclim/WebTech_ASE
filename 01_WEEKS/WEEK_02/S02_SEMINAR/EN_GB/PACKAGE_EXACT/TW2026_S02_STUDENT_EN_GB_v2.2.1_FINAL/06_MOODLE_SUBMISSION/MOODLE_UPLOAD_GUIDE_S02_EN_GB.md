# Moodle submission guide — S02

1. Complete the DOCX or HTML form during the activity.
2. For HTML, data remains in the local browser; use the validation button.
3. Export/print to PDF and open the PDF before uploading it.
4. Rename the file exactly according to the convention.
5. Open the Assignment in online.ase.ro, use Add submission and upload the PDF.
6. Use the final submission action if available; merely uploading a file may leave a draft.
7. Return to the Assignment page and verify the submission status.

Filename:
`TW2026_S02_GRUPA_Nume_Prenume.pdf`

Do not upload:
- parole / passwords
- token-uri / tokens
- cookie-uri de sesiune / session cookies
- chei API / API keys
- conversaţia Gemini completă / the complete Gemini conversation
