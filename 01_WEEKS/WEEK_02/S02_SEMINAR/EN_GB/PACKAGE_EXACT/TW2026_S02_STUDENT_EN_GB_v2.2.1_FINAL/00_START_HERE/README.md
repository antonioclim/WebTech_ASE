# Student package — Seminar 2 v2.1

The canonical core is U04-P01 Responsive Card/Grid Reconstruction. Edit only `01_PROIECT/RESPONSIVE_CARD_GRID_CANONIC/public/styles.css`.

## Start

1. Extract the complete archive.
2. Run `VERIFY_STUDENT_PACKAGE.cmd`.
3. Continue only after `VERDICT: PASS_PACKAGE_INTEGRITY_EXACT_SET`.
4. Run `VERIFY_INITIAL_STATE.cmd`: objective must fail only through assertions.
5. Run `START_PROJECT.cmd`. If Node.js v24.21.0 + npm 11.19.0 is unavailable, the offline laboratory opens.

## Optional extension

After the 60-minute core, open `02_LABORATOR_OFFLINE/CSS_MUSEUM_OF_BAD_IDEAS_v2.1_EN_GB.html`. The museum is a derived asset and does not modify the canonical project.
