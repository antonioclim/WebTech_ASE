S02 — Build a responsive card layout and measure the rendered result

v4.0.0 candidate teaching tutorial; the retained implementation folder is still named CLASSROOM_RC6. Complete all 3 projects individually. The full required route is planned for 120–165 minutes and remains unpiloted. Check the required runtime capabilities before class. These instructions do not award a grade or invent a deadline.

We will reconstruct a responsive card layout, make long content readable and observe keyboard focus and motion preferences. All three projects use the same stylesheet. Passing the source checklist is one step; the browser must also show that the content and controls remain available.

In C02 you explain which layer owns a defect. Here you make three particular relationships observable. Reuse C01/S01’s evidence rule: a server response, a source report and a screenshot support different claims.

What you will learn

  • Reconstruct grid and flex relationships at declared responsive breakpoints.
  • Allow long content to wrap without hiding it.
  • Inspect real keyboard focus and a real reduced-motion preference.

All three tasks edit one stylesheet. The Node checker recognises a narrow teaching syntax; it is not a rendering engine. Completion therefore requires your actual browser measurements as well as the source check. A page hidden with display:none, clipped content or invisible text is not a successful layout.
