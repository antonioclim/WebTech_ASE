Caz economic · 0–5 min

Aceeaşi cerere, alte riscuri

Interfaţa poate ascunde un defect de procesare chiar dacă datele par corecte.

Utilizatorul trebuie să

  • înţeleagă datele
  • corecteze erorile
  • ajungă la acţiune
  • observe rezultatul

Riscuri invizibile în captură

  • div clicabil
  • placeholder fără etichetă
  • status ascuns de cascadă
  • focus eliminat

Într-un sistem economic, pierderea controlului asupra interfeţei poate modifica decizia, nu doar estetica.

Semnificaţie · 5–13 min

HTML exprimă structură şi scop

Elementul nativ porneşte cu un contract de sens şi comportament pe care CSS nu îl poate fabrica retrospectiv.

<main>

Regiunea principală a documentului.

<button>

Acţiune, focus şi activare din tastatură.

<label>

Nume persistent şi ţintă de activare mai mare.

Mai profund: ARIA

ARIA poate expune relaţii necesare, dar nu face inutilă alegerea elementului nativ potrivit.

CSS poate schimba prezentarea; nu poate crea retrospectiv semnificaţia care lipseşte din document.

Structură · 5–13 min

Reperele şi titlurile formează o hartă

Nivelul titlului urmează ierarhia documentului. Mărimea vizuală aparţine CSS-ului.

mainh1 Cerere de decont
sectionh2 Datele cererii
sectionh2 Decizia
sectionh3 Justificare

Predicţie: ce se pierde dacă folosim h4 numai pentru că este mai mic?

Mărimea fontului este negociabilă. Relaţia dintre secţiuni nu este.

Element nativ · 5–13 min

Legătură, buton sau control?

Alegeţi proprietarul semantic al operaţiei, nu elementul care pare cel mai uşor de stilizat.

Scenariu: utilizatorul confirmă aprobarea fără a părăsi pagina.

Contraexemplu: o legătură poate porni o acţiune server-side, dar contractul perceput rămâne navigarea.

Preferăm elementul nativ al cărui contract semantic şi de interacţiune corespunde operaţiei.

Formulare · 13–22 min

Numele accesibil nu este placeholderul

Eticheta răspunde „ce este câmpul?”, iar descrierea răspunde „ce trebuie să ştiu?”.

<label for="amount">Suma</label>
<input id="amount"
  inputmode="decimal"
  aria-describedby="amount-hint">
<p id="amount-hint">RON, două zecimale</p>

Relaţii distincte

nume Suma

descriere formatul aşteptat

valoare datele introduse

O etichetă vizibilă şi un nume accesibil se pot suprapune, dar nu sunt aceeaşi relaţie.

Formulare · 13–22 min

Descriere, grupare şi stare de eroare

Afişarea textului nu garantează că relaţia este disponibilă programatic.

Selectaţi o relaţie.
Capcană: culoarea

O bordură roşie poate ajuta vizual, dar nu conectează singură eroarea cu controlul şi nu îi explică natura.

O eroare devine utilă numai când utilizatorul o poate găsi, interpreta şi corecta.

Cascadă · 22–32 min

Cascada selectează o valoare

Specificitatea este numai una dintre etapele procesului.

relevanţă→origine / importanţă→context / strat→specificitate→ordine

Domeniul demonstraţiei: declaraţii normale de autor, straturi, specificitate şi ordinea sursei.

Specificitatea nu conduce cascada; contează numai după criteriile care o preced.

Predicţie · 22–32 min

Ce regulă câştigă?

O regulă mai puţin specifică poate câştiga dacă se află într-un strat ulterior.

@layer legacy, theme;

@layer legacy {
  #claim .status { color: #9a3412; }
}
@layer theme {
  .status { color: #0f766e; }
}

Numărarea selectorilor înaintea stratului poate diagnostica exact invers cauza.

Dovadă DevTools · 22–32 min

Stilurile calculate explică rezultatul

Inspectăm declaraţia câştigătoare, concurenţii tăiaţi, moştenirea şi valoarea calculată.

#claim .status { color: #9a3412; } legacy
.status { color: #0f766e; } theme
computed color: rgb(15, 118, 110)

Întrebare: ce afirmaţie susţine această urmă şi ce nu poate demonstra despre contrast?

DevTools explică mecanismul observat; nu înlocuieşte testarea stării şi contextului relevante.

Layout · 40–48 min

Cine deţine geometria?

Responsive · 48–55 min

Responsive înseamnă intrări variabile

Spaţiul este numai una dintre intrări.

320 CSS pxzoom 200%font mai maretext tradustoken lungfocusreduced motion

Alegeţi trei intrări care pot rupe aceeaşi componentă fără a schimba dispozitivul.

Breakpoint-urile descriu nevoia conţinutului, nu o listă de mărci de telefoane.

Reflow · 48–55 min

O singură coloană nu este suficientă

La 320 CSS px, informaţia şi funcţia trebuie să rămână disponibile fără derulare în două dimensiuni, cu excepţii delimitate.

Selectaţi o stare.

Reflow-ul este o proprietate a comportamentului pe un interval de stări, nu a unei capturi alese convenabil.

Tastatură · 48–55 min

Focusul vizibil arată următoarea ţintă

Indicatorul trebuie verificat pe elementul focalizat, în traseul real de tastatură.

Apăsaţi Tab în browser. Un apel programatic focus() poate ajuta demonstraţia, dar nu dovedeşte traseul complet.

Focusul nu este decor. Este starea care face următoarea comandă previzibilă.

Preferinţe · 48–55 min

Mişcarea este prezentare, nu funcţie

La prefers-reduced-motion: reduce, acţiunea rămâne disponibilă, iar mişcarea neesenţială dispare.

Cerere procesată

Adaptăm prezentarea la preferinţă fără să eliminăm informaţia sau acţiunea.

Gemini sub audit · 55–58 min

Patru scurtături convenabile, patru contracte rupte

*:focus { outline:none; }
.card { height:12rem; overflow:hidden; }
.status { display:none !important; }

Gemini poate organiza ipotezele. Diff-ul, stilurile calculate şi comportamentul decid.

Extensie opţională · 60–63 min

Autopsia unei interfeţe aparent corecte

Captura este curată. Contractele sunt rupte în şase locuri.

Control

<div onclick> cu aspect de buton.

Nume

Placeholderul dispare când utilizatorul scrie.

Stare

Statusul este ascuns când nu încape.

Dimensiune

Cardul are height:12rem.

Ordine

order:-1 mută numai vizual acţiunea.

Mişcare

Tranziţia rămâne obligatorie.

Sarcină: pentru fiecare defect numiţi proprietarul, proba şi limita probei.

O interfaţă poate fi coerentă vizual şi incoerentă contractual.

Extensie opţională · 63–66 min

Cine a omorât statusul?

Nu acuzaţi specificitatea înainte de a inspecta toate declaraţiile aplicabile.

@layer base, theme, emergency;
@layer base { .status { display:inline-flex; } }
@layer theme { #claim .status { color:#0f766e; } }
@layer emergency { .status { display:none !important; } }

Urmaţi: matched rules → declaraţie câştigătoare → computed style → geometrie.

Computed style nu ghiceşte vinovatul. Îl arată pentru starea inspectată.

Extensie opţională · 66–69 min

Butonul frumos care nu este buton

cursor:pointer schimbă cursorul. Nu adaugă rol, focus sau tastatură.

Imitaţia

<div class="approve" onclick="approve()">Aprobă</div>

Trebuie reconstruite manual focusul, Enter/Space, disabled şi numele.

Contractul nativ

<button type="button">Aprobă</button>

Porneşte cu semantică şi operare prin tastatură definite.

Elementul nativ nu elimină testarea. Elimină o parte din comportamentul pe care altfel l-am inventa.

Extensie opţională · 69–72 min

Responsive înseamnă mai mult decât coloane

Un layout poate respecta 1/2/4 coloane şi totuşi să piardă sens, conţinut sau control.

Extensie opţională · 72–75 min

CSS courtroom

Patch-ul arată mai curat. Acuzaţia cere însă mecanism şi probă.

*:focus { outline:0; }
.card { height:12rem; overflow:hidden; }
.status { display:none !important; }
.approve { cursor:pointer; }
body { overflow-x:hidden; }

Capete de acuzare

  • focus invizibil
  • conţinut tăiat
  • stare eliminată
  • semantică absentă
  • simptom ascuns

STOP extensie la minutul 75.

Nu judecăm autorul patch-ului. Judecăm fiecare afirmaţie printr-o verificare care o poate falsifica.
