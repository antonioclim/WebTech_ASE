1. Autopsy with measured quantities

The width control changes an actual nested iframe viewport. A wide example can require scrolling in the host. Text size and reduced motion buttons are explicitly labelled simulations. They do not change native browser zoom or your operating system preference.

The nested example is loading.

This diagnosis describes the current example state. It does not certify the whole product.

Native browser zoom is a separate check

Use your browser menu to set zoom to 200%. Record that menu value, then test reading, clipping and keyboard operation. Reset it afterwards. The iframe still has its selected CSS viewport width; resizing the browser and native zoom are different inputs. Do not report the text size simulation as a native zoom observation.
