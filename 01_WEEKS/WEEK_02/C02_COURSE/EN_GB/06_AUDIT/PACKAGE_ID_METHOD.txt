PACKAGE_ID is SHA-256 of UTF-8 lines "SHA-256  relative/path\n" sorted by exact ordinal relative path, covering every file except 06_AUDIT/PACKAGE_ID.txt and 06_AUDIT/SHA256SUMS.txt. SHA256SUMS.txt lists every file except itself, in the same order, including PACKAGE_ID.txt. The ID file is one lower-case 64-hex line followed by LF. Verifiers reject missing or invalid identities, unsafe or duplicate paths, case collisions, symlinks/reparse entries, missing/extra files and hash differences. Integrity is not pedagogical or platform acceptance.
