## Browse without downloading
Open a week, then its course or seminar, then EN_GB. The language README links to the complete PACKAGE_EXACT tree and individual documents. GitHub shows HTML source, not an interactive lesson. DOWNLOAD remains available for local use; this route does not activate Pages or change qualification status.

## Use a downloaded week
Open the ZIP file on GitHub and use **Download raw file**. Extract the complete ZIP to a new short folder, then open `index.html`. Do not open it from inside the compressed archive. Complete teaching sources remain inside each archive and are also available, byte-for-byte, in each object’s EN_GB/PACKAGE_EXACT directory. The established Weeks 01–02 layout is unchanged.

## Limits
A README or successful download is not application acceptance. Read each week’s qualification notice. Missing dependencies must be resolved through a separately authorised setup, not ignored. No Actions, Pages, Releases or Moodle changes are needed to download these files.
