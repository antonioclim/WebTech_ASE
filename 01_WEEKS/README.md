## Open downloaded material

Individual object ZIPs contain the selected course or seminar. Whole-week ZIPs contain two nested object ZIPs: extract the outer archive then each object archive into a separate writable folder. The complete collection ZIP has already extracted objects under `PACKAGES`; extract that collection once. Follow each object's named guide because there is no universal start filename. GitHub displays HTML source rather than an interactive lesson.
