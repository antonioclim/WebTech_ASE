C11 — Preparation and Transfer

Before the course: read, predict, distinguish

Read the package index, SOURCE_NOTES.md and the opening handout sections. This phase requires no installation, external account, password, session cookie or server. Inspect the five canonical example directories as source files; their historical run instructions are not an instruction to start them now.

Write a short prediction for each of these distinctions: TLS versus principal verification; principal verification versus a specific permission; server expiry versus a cookie lifetime; response sharing versus request intent; bound data versus SQL execution. Name the boundary rather than a library alone. Use fictional labels instead of copying private requests.

During the 60-minute course

Follow the eight intervals in course.html. At each intermezzo, make the prediction before revealing the explanatory model. The model accepts only a selected fixed scenario and a text prediction. Its output is explicitly synthetic and cannot be substituted for an observed Express or browser result.
