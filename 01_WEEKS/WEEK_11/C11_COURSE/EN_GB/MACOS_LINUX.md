# C11 — macOS/Linux route

Extract to a new empty folder. Open index.html for reading and verify that navigation/controls actually load. In a terminal, cd to C11_COURSE/EN_GB, then run:

```text
bash CHECK_ENVIRONMENT.sh
bash RUN_ALL_EXAMPLES.sh
```

These are the four neutral demonstrations, not canonical server scripts. Use RUN_EXAMPLES.md for selected core/SQLite/HTTP profiles and exact diagnostics. Native macOS/browser/print acceptance is unexecuted; actual command QA used Linux Node 24.19.0. No install is performed.
