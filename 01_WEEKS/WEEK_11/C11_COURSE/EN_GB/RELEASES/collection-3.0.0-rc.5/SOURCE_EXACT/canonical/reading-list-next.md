# Reading list for the next lecture — Lecture 12 — Realtime Communication and Asynchronous Work

Complete these readings before Lecture 12 — Realtime Communication and Asynchronous Work.

- [MDN: The WebSocket API](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API) — understand persistent, bidirectional browser connections and API limitations.
- [MDN: Using server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events) — compare one-way event streams with WebSocket communication.
- [BullMQ: Queues](https://docs.bullmq.io/guide/queues) — enqueue durable work and understand job options and identifiers.
- [BullMQ: Workers](https://docs.bullmq.io/guide/workers) — process jobs, report progress, and handle completion and failure.
