# Exact wrapper identity

SHA256SUMS.txt covers every regular file except itself and PACKAGE_ID.txt. Lines use lowercase SHA-256, two spaces, the relative POSIX path and LF, sorted by path. PACKAGE_ID.txt is SHA-256 of the exact manifest bytes followed by LF. ZIP entries use timestamp 2026-09-30 00:00:00, regular-file mode 0644 and deflate level 9. External ZIP hashes belong only in sidecars or external receipts. Nested packages retain their original identity methods and bytes. Integrity does not grant runtime, browser, platform, security or publication acceptance and is not a repository FINAL identity.
