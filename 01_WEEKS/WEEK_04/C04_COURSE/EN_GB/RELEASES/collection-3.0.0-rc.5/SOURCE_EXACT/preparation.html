C04 — Preparation and transfer

Before the meeting: identify the two routes

The presentation and laboratory are self-contained course materials. Extract the whole public ZIP and open index.html. No server, installation, sign-in or internet connection is required for those pages. The canonical browser module example is a different route, served by the included loopback helper when Node is already available. Follow guide.html rather than the historical headless command in the canonical README.

Read handout sections 1–2 and recall Week 03’s distinction between identity and copies. Inspect canonical/01-module-live-binding/state.js and summary.js. Identify the private binding, exported functions and the returned projection. Do not describe this function-based example as a direct imported mutable binding.

Before observing a result, predict the five labels in canonical example 02. In a second prediction, distinguish initiation, completion and result order for three independent operations. Write a reason, not just a permutation. These predictions can be kept locally; they are not a separate Moodle assignment.

Check the package version and preserve the original ZIP before editing anything in a later seminar. For optional Node examples, record node --version and npm --version rather than copying the reference versions as though measured. The project reference is Node v24.21.0 with npm 11.19.0. Do not install a global tool or replace an environment as part of this course reading route.

During the meeting: make the witness discriminate

Use course.html for the 24-screen route. Previous/Next, the selector and arrow/Page keys navigate; Home/End select the first/last screen. Editing a field or using a focused control retains its own keys. Text size ranges from 40% to 160%, separately from browser zoom. Reading mode shows the full route. Print includes explanations; preview before saving.

In lab.html, choose a controlled experiment and enter a prediction. Run one scenario at a time. The session labels promise and fake-response records MODEL_OR_INJECTED, not real traffic. Use the event area to compare the actual target with the listener owner. Unbind, activate while unbound, then rebind once; note the difference between no callback and an empty-looking output.

For a non-success response, inspect whether parsing was called. For an aggregate rejection, inspect whether other operations still completed. For a stale completion, distinguish an ignored commit from cancellation. These witnesses are more informative than a single final success message.

Explicit JSON export is the portable course-lab save route. The course lab does not use localStorage. Imported records are labelled unverified and do not become new executions. Data entry is local and contains no student identity requirement. Clear removes this page’s session records, not exported files or browser backups.

Closing at minute 60

Write one mechanism, one observed input/action/result and one limitation. Keep an unresolved question visible rather than converting it into PASS. Identify P01 as the next seminar’s central project and P02 as the later required portfolio. End the course; do not start an optional retry implementation inside the reserved time.

The laboratory is a teaching tool. It does not run a student Dashboard implementation, generate official test acceptance or upload anything to Moodle. An attractive trace is not a substitute for the subsequent seminar’s evidence contract.

After the meeting: connect concepts without enlarging the assessment

Revisit the four Node-compatible canonical examples in fresh processes. Compare the outputs with your earlier predictions. The event example requires a browser, so Node assertions cannot certify it. The supplied guide gives a local HTTP route with an explicit address and stop command. A reported server address is not proof that a browser opened or that its events were correct.

Read the S04 package when it is delivered. P01 is Multi-source Data Dashboard. P02 Interactive Task List is the required later portfolio; its source estimate is 45–60 minutes outside the meeting, not a completion guarantee. P03 Resilient Fetch is optional; its 50–65-minute source estimate must not be hidden inside the core or the standard mark.
