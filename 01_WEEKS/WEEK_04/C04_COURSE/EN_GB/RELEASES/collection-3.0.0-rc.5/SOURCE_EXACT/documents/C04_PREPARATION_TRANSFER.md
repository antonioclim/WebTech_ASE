## During the meeting: make the witness discriminate
Use course.html for the 24-screen route. Previous/Next, the selector and arrow/Page keys navigate; Home/End select the first/last screen. Editing a field or using a focused control retains its own keys. Text size ranges from 40% to 160%, separately from browser zoom. Reading mode shows the full route. Print includes explanations; preview before saving.

In lab.html, choose a controlled experiment and enter a prediction. Run one scenario at a time. The session labels promise and fake-response records MODEL_OR_INJECTED, not real traffic. Use the event area to compare the actual target with the listener owner. Unbind, activate while unbound, then rebind once; note the difference between no callback and an empty-looking output.

For a non-success response, inspect whether parsing was called. For an aggregate rejection, inspect whether other operations still completed. For a stale completion, distinguish an ignored commit from cancellation. These witnesses are more informative than a single final success message.

Explicit JSON export is the portable course-lab save route. The course lab does not use localStorage. Imported records are labelled unverified and do not become new executions. Data entry is local and contains no student identity requirement. Clear removes this page’s session records, not exported files or browser backups.
