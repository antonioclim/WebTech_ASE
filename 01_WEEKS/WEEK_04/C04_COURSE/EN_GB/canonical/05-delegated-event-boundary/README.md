# Canonical delegated event boundary

This broad course example resolves an action from a nested origin and checks ownership. It is not the full S04 button/row/accepted-action contract and it only logs an action rather than deleting a task. The page performs an initial scripted click; its first output is synthetic.

From `01_WEEKS/WEEK_04/C04_COURSE/EN_GB` run `node tools/tw-kit.mjs serve`, copy the actual READY origin and follow `/event/`. Compare your actual nested-label click with button activation and record browser/version, action and output. A successful HTTP route is not native browser evidence.

Stop using Ctrl+C in the owning terminal and wait for `STOPPED: loopback listener closed.` Keep blocked or unexecuted native actions visible. Use [the launch guide](../../guide.html) for exact scope. No headless/browser-security workaround is required or authorised.
