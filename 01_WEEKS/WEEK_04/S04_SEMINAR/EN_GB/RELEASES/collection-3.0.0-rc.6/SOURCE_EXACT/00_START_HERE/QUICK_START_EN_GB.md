# S04 quick start

1. Extract the ZIP. Do not open files from inside the archive.
2. Open the extracted package root in VS Code.
3. Run `VERIFY_PACKAGE`.
4. Open the interactive guide.
5. Save the prediction before executing P01.
6. Run `VERIFY_INITIAL_STATE`.
7. Edit only the permitted file for the current project.
8. Stop the core at T60.
