# S04 glossary

- **initiation** — creation or start of an asynchronous operation
- **completion** — fulfilment or rejection of an operation
- **transport rejection** — no usable HTTP Response is obtained
- **HTTP non-success** — a Response exists but `response.ok` is false
- **parse failure** — a body conversion such as `response.json()` rejects
- **aggregate position** — the result index defined by the input promise order
- **injected witness** — a controlled substitute that exposes a mechanism
- **local HTTP evidence** — evidence from a loopback server such as `127.0.0.1`
- **real-browser evidence** — evidence actually observed in a named browser and version
- **event delegation** — one ancestor listener resolves actions from descendant targets
- **cleanup** — explicit removal or termination of a listener, timer or process
