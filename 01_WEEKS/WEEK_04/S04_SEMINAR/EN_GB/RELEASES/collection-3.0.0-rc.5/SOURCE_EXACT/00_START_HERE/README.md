## First gates

1. Extract the complete ZIP into a real folder.
2. Run `VERIFY_PACKAGE`.
3. Run `CHECK_ENVIRONMENT` and record MATCH, MISMATCH or ABSENT.
4. Preserve the fixture prediction before running P01.
