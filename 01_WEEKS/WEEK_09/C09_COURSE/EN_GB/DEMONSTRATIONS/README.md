# C09 — authored neutral demonstrations

These four complete examples have different teaching objects from the assessed S09 functions. Canonical01–05 and existing assets/derivatives remain byte-exact. Run from C09 EN_GB with `node tools/tw-kit.mjs example 01` through 04 or the all-examples wrapper described in RUN_EXAMPLES.md.

01 reads a library URL and applies explicit array-history operations. Predict push Back→/books/new and replace Back→/books, given the declared two-entry baseline. The single-entry control has no supplied predecessor. This is no route parser or native History API.

02 imports the actual canonical04 adapter and requestNote derivative. Predict SyntaxError/jsonReads 1 for canonical malformed 503 and HTTP 503/jsonReads 0 for the derivative. The seven extra derivative cases distinguish the failure frontier and projection. All fetch responses are injected, not network observations.

03 creates a separate equipment-label Node HTTP fixture. Predict Stored label, accepted MIXED CASE, invalid_label 400, independent retained MIXED CASE, successful malformed JSON and equipment_not_found 404. Six actual requests are required before its PASS. Only this listener’s in-memory state is witnessed.

04 has explicit literal library handlers rather than a general SPA fallback classifier. Predict document GET bytes and HEAD zero body with the same Content-Type/length, script bytes, missing script 404, health JSON 200, missing service 404 and POST 405. Seven requests and owned cleanup are witnessed. The scriptless document does not boot a client; fetching the separate script does not execute it.

All predictions become observations only when the specified source is run. Each direct source uses the local capability guard, bounds HTTP requests where used and closes only its own listener. Framework/native/browser/durability conclusions require separate evidence.
