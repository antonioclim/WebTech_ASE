# Instructor support preview — not the assessed tree
The component client/src/NotesWorkspace.jsx is the exact incomplete student starter. The source package and lockfile are unchanged. Two support derivatives are declared: client/src/notes-api.js and server/preview-server.mjs (new). The original server/server.js is retained but is NOT the recommended standalone launch path for this preview.
Do not substitute this directory for capstone/p02/student in the one-file assessment. After separate environment qualification: from this directory use node server/preview-server.mjs --start-local and the existing npm run dev in another terminal. No install occurs in the launcher. No server was run during package production.
The adapter implements list/create/update/remove, not an invented get endpoint. It classifies selected transport/protocol/schema cases; it is not a general JSON-schema or security validator. It preserves AbortError and rejects duplicate list IDs. The API remains volatile, local and unauthenticated; never expose this teaching preview beyond loopback.
