# S05 glossary

- **parser** — converts request bytes into a JavaScript value or rejects malformed syntax
- **router** — matches an HTTP method and resource path
- **repository** — owns the in-memory task state
- **media type** — describes the representation, such as `application/json`
- **Location** — response header identifying the created resource
- **204** — successful response with no representation in this project contract
- **middleware** — a function participating in the request/response pipeline
- **TAP** — deterministic text output from the Node test runner
- **evidence class** — a label describing what was actually executed or inspected
