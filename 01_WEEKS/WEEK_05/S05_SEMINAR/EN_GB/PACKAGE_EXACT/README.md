# S05 — In-memory Task API

Version 1.1.0. Public student-content candidate; reference-runtime, real-browser and native acceptance remain separate. Start with `index.html` after extraction. Read `guide.html` before commands.

P01 is the only required implementation. The C05 guided P02 observation is required reflection; complete P02/P03 implementations are optional. One final individual PDF is submitted later, after the completion window. The seminar has seven stages ending explicitly at minute 60.

Public entry points: `seminar.html`, `evidence.html`, `guided.html`, `guide.html`, `continuation.html` and `moodle.html`. The three full public contracts are in `contracts`. The editable form and short guides are in `documents`.

The presentation and form are direct-file offline pages. The API needs prepared local Express dependencies and loopback HTTP. The tools do not install, download or publish anything. `MODULE_NOT_FOUND` is an environment block, not an expected student assertion. Use the setup route separately; never install globally.

Windows: `WINDOWS.md`. macOS/Linux: `MACOS_LINUX.md`. The source README/package metadata remain exact canonical copies, including historical terminology and commands. The current top-level guide is the operational route; do not run historical install/browser-smoke automation from a copied source README.

Only `projects/p01/src/task-router.js` may change in the required project. Tests, fixtures, repository, app and lockfile are preserved. Keep logs outside the project roots. Exact manifests and package-ID rules are documented in `PACKAGE_ID_METHOD.md`; a changed exercise copy is not expected to match the original package manifest after editing.
