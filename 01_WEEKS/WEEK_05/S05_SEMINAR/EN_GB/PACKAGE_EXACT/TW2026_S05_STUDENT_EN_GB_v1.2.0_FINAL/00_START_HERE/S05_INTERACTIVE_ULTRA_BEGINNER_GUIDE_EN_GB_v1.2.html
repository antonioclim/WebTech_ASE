Bounded Gemini audit

Open a new browser tab, go to Gemini Web, start a new chat and verify that the prompt contains no password, token, cookie, private code, Moodle data or real personal data. Submit once.

Review this bounded S05 claim without using private data: “If an API response has status 400, the router must have produced it, and an empty DELETE response should still be parsed as JSON.” Identify each testable assertion, propose the smallest independent check, classify what is observed versus inferred and finish with ACCEPTED, REJECTED, PARTIALLY ACCEPTED or UNKNOWN plus one limitation.
Reveal expected counterexamples

Malformed JSON may be rejected by the parser before the router. A successful DELETE 204 has zero body bytes under this project contract and must not be parsed as JSON.

Glossary

Parser
Software that converts request bytes into a JavaScript value or rejects malformed syntax.
Router
The component matching method and resource path.
Repository
The in-memory state owner in this exercise.
Location
A response header identifying the created resource.
204
Successful response with no representation in this project contract.
Evidence class
A label preventing a weaker observation from being presented as a stronger execution.
