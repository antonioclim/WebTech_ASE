# S05 quick start

1. Extract the ZIP.
2. Open the extracted package root.
3. Run `VERIFY_PACKAGE`.
4. Run `CHECK_ENVIRONMENT` and record the exact classification.
5. Open the beginner guide.
6. Write the prediction before execution.
7. Run `VERIFY_INITIAL_STATE`.
8. Edit only the permitted file.
9. Stop the core at T60.
