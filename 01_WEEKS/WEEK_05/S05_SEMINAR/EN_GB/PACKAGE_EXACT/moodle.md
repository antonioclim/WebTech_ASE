# S05 final submission

Assignment title proposed for the course: **TW2026 — S05: In-memory Task API and HTTP Contract Evidence**. The live course location, dates and file-size limit are configured by the teacher later. They have not been verified by this local kit.

## Export from the HTML form

Open `evidence.html` from the extracted kit. Enter evidence progressively. Export JSON as a portable draft backup and confirm it exists in your download folder. JSON is a working copy, not the final submission.

Use **Check core draft** at the end of class. For the final submission, complete all required sections and choose truthful evidence states, then **Check final fields**. That checks data structure and completeness, not code correctness or authenticity.

Use **Print final PDF** and select the browser/system PDF destination. Review the preview and all printed pages. Use the filename displayed by the form; the page cannot force every operating-system save dialogue to adopt it. Missing or invalid final fields block the final-print button. Ordinary Ctrl+P prepares a clearly labelled core draft, not a silently approved final.

Long evidence appears as normal paragraphs in print. The HTML supports text excerpts, not image attachment uploads. For labelled screenshots use the editable DOCX route, preserving the same 48 field identifiers and section order. A screenshot is not a substitute for a reproducible command/input description.

## Export from DOCX

Open `documents/S05_EVIDENCE_FORM.docx` in a compatible word processor. Replace the response placeholders without deleting field identifiers or headings. The document expands as you type; it is not a fixed-page limit. Add screenshot captions and the corresponding command or input description when needed.

Use the word processor's PDF export or Print to PDF. Review every page of the actual saved PDF. Do not submit the DOCX or claim that the HTML validation ran on the Word file. Complete and review the declaration yourself.

## Filename and scope

```text
TW2026_S05_GROUP_Surname_GivenName.pdf
```

Replace GROUP and the names with your own details. For example, `TW2026_S05_1099_Example_Student.pdf` is synthetic, not a real student's submission. Student identity belongs only in the private assessment submission, never a public repository.

The PDF covers the complete required P01 work and the guided P02 observation. Full P02/P03 code is optional and cannot be required for full marks. No separate C05 Assignment exists in this design. The final deadline must allow completion after the live seminar; use the date actually shown on the course site.

## Correction and privacy

For a wrong file or missing evidence, follow the teacher's reopening/correction instructions. Preserve your original evidence and identify the correction. Do not invent earlier observations or alter the original prediction after the fact.

Never upload passwords, tokens, cookies, private datasets or a complete Gemini conversation. The requested excerpt is the relevant prompt, claim and independent check. No code ZIP or source repository is the final assessment file in this contract.
