# Reading list for the next lecture — Lecture 13 — Browser and Application Composition Architectures

Complete these readings before Lecture 13 — Browser and Application Composition Architectures.

- [MDN: Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API) — understand origin-scoped synchronous storage and its limits.
- [MDN: Using Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers) — move CPU work off the main thread through a message protocol.
- [MDN: Service Worker API](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API) — trace registration, installation, activation, control, and fetch interception.
- [MDN: `window.postMessage()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage) — send cross-context messages with exact origin and source checks.
