# S12 individual PDF upload route — v1.2.1 FINAL_LOCAL

Use the actual teacher-set deadline and authorised course. These are generic Moodle labels verified against official documentation; online.ase.ro's theme, version and translated labels have not been observed. The package performs no upload.

Before Moodle, open your actual saved PDF. Read every page and verify CODE belongs to your approved alias, the name is `TW2026_S12_CODE.pdf`, all 49 fields and evidence metadata are legible, required work is actually complete and sensitive data is absent. A print dialogue is not a saved-file receipt. A blocked required task remains an honest draft under actual teacher policy.

1. Open a browser tab, select the address bar, type `https://online.ase.ro` and press Enter. Sign in through your authorised institutional route. If access is blocked, record the actual error and contact the teacher using the agreed course route; do not invent a submission.
2. Open the actual Web Technologies course, find Week 12 and the S12 Assignment. Check the title identifies the correlated request dispatcher and individual HTTP/WebSocket trace. STOP if you have another course/week/activity, a C12 Assignment or an optional P02 activity.
3. Read the displayed instructions, allowed file type/count, deadline and rubric. Select Add submission or its equivalent. If unavailable, check the displayed availability or actual error with the teacher. Do not guess a replacement activity.
4. Drag your one reviewed PDF into the file area, or use its file-picker control and choose the PDF. Wait until the displayed file finishes uploading. Check the shown filename. Do not select your source ZIP, project folder or node_modules.
5. Select Save changes or its equivalent, wait for the status page and inspect the displayed PDF name. Saving can retain Draft depending on settings. If corrections are required, use the actual edit route before final submission.
6. For the configured final-submit route, select Submit assignment or its equivalent. Read and accept only the actual applicable declaration, confirm if prompted and wait for the returned status page.
7. Observe the actual final status, displayed PDF filename and timestamp. The documented final English status is Submitted for grading; translated or themed labels may differ. Record the actually displayed wording and timestamp with timezone when visible. Do not confuse Grading status with Submission status.
8. STOP if status remains Draft (not submitted), no final status is visible, the wrong filename appears or an error occurs. Retain your PDF, record the limitation and follow the teacher's existing route. Do not declare final submission from a button click alone.

The form's READY_NOT_SUBMITTED means local readiness; SUBMITTED_UNVERIFIED remains an unverified declaration until supported by the actual instance. Keep a private receipt note containing actual activity title, status, filename and timestamp without credentials or private account screenshots. Reopening the status page can confirm persistence; it does not certify teacher approval or a grade.
