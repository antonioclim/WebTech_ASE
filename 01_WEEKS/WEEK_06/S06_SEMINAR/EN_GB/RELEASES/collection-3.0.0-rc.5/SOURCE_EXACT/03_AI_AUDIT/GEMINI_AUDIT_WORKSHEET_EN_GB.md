# S06 — audit one AI claim

Student edition v1.2.0. An AI response is an object for critical examination, not a substitute for your own implementation or measurement. Review one claim and keep the evidence boundary explicit.

## Prepare a bounded actual interaction

Open your own authorised Gemini service in a new browser tab and start a new conversation when that option is available. Interface labels vary; this instruction is illustrative rather than a verified screenshot of a live service. Use `GEMINI_PROMPT.txt`. Read the complete prompt and remove personal information, passwords, tokens, cookies, private code, Moodle credentials and genuine private datasets before sending it. Do not submit the full kit, reference solution or assessment form.

Ask one narrow question using a short sanitised rule and excerpt. Do not request the complete translator, changes to tests or another dependency. Send the prompt once, wait for the complete response and copy one short claim accurately. Record the service/model label as actually displayed, with the date; do not invent a version.

If the service is unavailable, record the actual block and save the draft. The synthetic exercise below can support practice, but the actual E6 interaction remains pending unless a separate teacher decision specifically authorises an alternative.

Classify the claim as **Observed**, **Inferred** or **Unknown**. Observed means the cited measurement actually records the proposition at its identified boundary. Inferred means the proposition is a reasoned interpretation whose assumptions still need to be stated. Unknown means the supplied material cannot decide it. These labels do not certify that the evidence itself is authentic.

A different prompt to the same model is not an independent execution check. A source inspection can support a mechanism explanation but must not be labelled as native database execution. A route response does not measure a direct model-call count unless a specific counter/spy provides that observation. A same-process connection reopen is not a power-loss experiment.

## Part C — decide and correct

Select **Accepted**, **Rejected**, **Partly accepted** or **Unknown**. Justify the selection from your own check. Write a corrected sentence that says only what the identified evidence supports. Then state one remaining limitation and a sensible next check. Do not claim teacher authorisation or approval merely because a form is complete.
