1 Save and inspect the PDF

WHERE YOU ARE
The offline S06 form in the extracted student package, with your own current entries.
WHAT TO FIND
Print core draft for the first export, the browser print destination and the saved file.
EXACT ACTION
Choose Print core draft. In the print dialogue choose Save as PDF, all pages and readable scale. Save the file. Open it from the download/save folder, inspect every page and record the result in export_inspection. Complete the final fields and declaration, choose Check final fields, then Print final PDF. Save and inspect the final PDF again.
WHAT YOU SHOULD SEE
One readable PDF containing all seven sections, complete long values and the current declaration. The suggested name is TW2026_S06_GROUP_Surname_Firstname.pdf, for example TW2026_S06_1042_Popescu_Ana.pdf.
WHAT TO RECORD
Actual filename and the result of inspecting every page. Keep the private JSON draft separately.
DO NOT CONTINUE UNLESS
The final file is saved, opens correctly and includes the current complete evidence. A green form label checks structure only.
IF YOU DO NOT SEE THIS
Cancel upload. Repair clipped text or missing values, export again and inspect the newly saved file. Use the DOCX route if necessary. CLI text evidence is acceptable; screenshots are not required.
STOP CONDITION
A draft, unreadable page, clipped evidence, missing declaration or unsupported final claim. A print dialogue or requested download alone does not establish a saved file.
CONTINUE WITH
Step 2: locate the correct S06 Assignment.

2 Locate the correct S06 Assignment

WHERE YOU ARE
Your own signed-in Moodle course page on the university platform, using the current course instructions.
WHAT TO FIND
Assignment titled S06 — Query API: individual evidence, or the teacher-confirmed live S06 title.
EXACT ACTION
Sign in yourself, open the correct Web Technologies course, navigate to the S06 area and open the Assignment. Read its current description, deadline, allowed file type, size limit and final-submit requirement.
WHAT YOU SHOULD SEE
The correct S06 activity and its submission area. The package does not set or verify live dates.
WHAT TO RECORD
The exact live Assignment title and announced deadline. Do not copy account credentials into your evidence.
DO NOT CONTINUE UNLESS
You recognise the correct course and S06 activity. One final PDF belongs to S06; there is no second C06 upload in this teaching contract.
IF YOU DO NOT SEE THIS
Recheck the course/section and current teacher instructions. A renamed, unavailable or locked activity needs the teacher’s current guidance.
STOP CONDITION
Wrong course/title, missing activity or a locked submission area. Do not upload to an unrelated activity.
CONTINUE WITH
Step 3: upload the inspected PDF.

3 Upload and save the single PDF

WHERE YOU ARE
The correct S06 Assignment submission area.
WHAT TO FIND
Add submission or Edit submission and the file-submission box/file picker. Labels depend on the site configuration.
EXACT ACTION
Choose Add submission or the available edit action. Click the file picker, choose Upload a file, select your inspected PDF and confirm upload. Drag-and-drop is an alternative only if the site supports it. Wait until the filename appears and progress has finished, then choose Save changes.
WHAT YOU SHOULD SEE
The current PDF filename listed under File submissions after saving. The live size limit applies; this package cannot increase it.
WHAT TO RECORD
The saved filename and any real technical block. Keep the final PDF locally.
DO NOT CONTINUE UNLESS
Exactly the intended current PDF is attached and saved. Do not upload ZIP, project code, node_modules, DOCX, JSON draft, private teacher kit or full AI conversation.
IF YOU DO NOT SEE THIS
Wait for actual upload completion. If a file type/size error appears, read the live limit, correct the file and retry only while the Assignment permits editing.
STOP CONDITION
Upload error, wrong file, duplicate files or filename missing after Save changes. An upload bar is not final submission confirmation.
CONTINUE WITH
Step 4: complete final submission and read its status.

4 Complete final submission and verify its receipt

WHERE YOU ARE
The saved S06 Assignment submission summary.
WHAT TO FIND
Submission status, Submit assignment if present, the submission declaration/confirmation if present and the last-modified/submission timestamp.
EXACT ACTION
If Submit assignment is present, click it after reviewing the filename. Complete the required declaration and confirmation. Return to the summary and read the resulting status, filename and timestamp. If the teacher-confirmed workflow uses a different final action, follow that live instruction.
WHAT YOU SHOULD SEE
A final status such as Submitted for grading and the current PDF filename, plus the platform’s displayed timestamp. Exact wording and timestamp label vary. A saved draft is not final.
WHAT TO RECORD
Actual filename, displayed final status and timestamp, or a real block. Retain the final PDF and confirmation locally. A screenshot may help privately but is not a mandatory student assessment artefact.
DO NOT CONTINUE UNLESS
The platform indicates final submission under its configured workflow. The offline form cannot confirm this.
IF YOU DO NOT SEE THIS
If status is Draft, complete the final-submit action if available. If the activity is locked or status remains ambiguous, preserve the actual message and ask the teacher for the approved correction route.
STOP CONDITION
Status remains Draft, wrong filename, failed confirmation or no teacher-confirmed final state. Do not declare submission merely because Save changes succeeded.
CONTINUE WITH
Retain the submitted PDF and actual confirmation. If correction is needed, use Step 5.

5 Correct a submission only through the allowed route

WHERE YOU ARE
The current S06 submission summary with a genuinely wrong or superseded file.
WHAT TO FIND
Edit submission if the platform still permits it, or the teacher’s contact/correction instructions.
EXACT ACTION
If editing is enabled, replace the wrong file with the inspected current PDF, save and repeat the final-submit/status checks. If locked, ask the teacher with the Assignment title, filename and a brief description of the problem. A reopening is a separate teacher action.
WHAT YOU SHOULD SEE
The corrected current filename and final status, or an accurately recorded locked-state message.
WHAT TO RECORD
The actual correction outcome and current confirmation. Retain earlier files locally with clearly different names if needed.
DO NOT CONTINUE UNLESS
The correction route is allowed by the live activity or a separate teacher decision.
IF YOU DO NOT SEE THIS
Keep the actual block. Do not create an unrelated second submission or silently claim the corrected file was received.
STOP CONDITION
Locked editing without a teacher decision, wrong activity or unconfirmed final correction.
CONTINUE WITH
Retain the actual submission record; complete any separate teacher-requested action.
