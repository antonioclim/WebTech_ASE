Use the form and preserve your evidence
  1. Record Predictions A, B and the lifecycle prediction before executing their observations. Keep a wrong original prediction.
  2. Enter the date, seminar ID, observed kit version and PACKAGE_ID separately. PACKAGE_ID identifies the package; a process PID identifies one running process.
  3. Use Check core draft while working. PENDING or BLOCKED may remain in an honest core draft. Check final fields requires the standard actual evidence or a separately obtained teacher decision.
  4. Export JSON, then find the saved JSON file and confirm its name. JSON is a private portable draft and is not uploaded to Moodle.
  5. For a first PDF, choose Print core draft, save as PDF and inspect every page. Enter the inspection in export_inspection, complete final requirements and renew your declaration.
  6. Choose Check final fields, then Print final PDF. Save and open that final file too; confirm all long values, code, names and the declaration. A print dialogue is not proof that the file saved.
