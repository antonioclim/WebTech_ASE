# Submit one final PDF on Moodle

Complete the core implementation and required evidence before the published deadline. The Assignment is **TW2026 — S06: Query API and Persistence Evidence**. Its dates are set later by the teacher; no date in this local package overrides the live course notice.

Open `evidence.html` and restore your JSON draft, or complete the DOCX form. In HTML, review imported data and renew the declaration. Select Check final fields. A complete result checks the fields, not whether the programme is correct or observations are true. Resolve missing evidence or enter a separately obtained teacher decision with its reference and scope.

Select Print final PDF, then the browser's Save as PDF destination. Check the page range includes all pages, keep readable scale and remove unrelated browser headers/footers where available. The suggested name is `TW2026_S06_GROUP_Surname_GivenName.pdf`. Replace GROUP and the name fields with your actual details. The page cannot force every operating system's filename dialogue: confirm the resulting name yourself.

Open the saved PDF before uploading. Check all sections, code excerpts, long lines, non-ASCII names and the final declaration. Missing or cut-off evidence is not repaired by a correct filename. For screenshots use the editable DOCX route and add a caption with the command/input and evidence class; an image alone is not a reproducible experiment. Export the completed DOCX to PDF, then inspect it in the same way.

On `online.ase.ro`, sign in yourself, open the correct Web Technologies course and locate the S06 Assignment. Choose its add/edit submission action, upload the single PDF and save. When the platform requires a further final-submit action or declaration, complete that action. Read the resulting submission status and confirm that the filename is the current one. A saved draft or an upload progress bar is not confirmation of final submission. Exact labels may differ in the site's configuration; use the teacher's current course instructions if they differ.

Retain the final PDF and submission confirmation locally. Do not upload a ZIP, DOCX, JSON draft, full Gemini conversation, private reference solution, credential or genuine private dataset. The proposed limit is one PDF up to 10 MB only where the site permits it. Follow a lower live limit rather than assuming the package can change it.

If the wrong file was uploaded, use Edit submission only if the platform still permits it. If it is locked, contact the teacher with the Assignment name, filename and a brief technical description. Do not create a second submission elsewhere. A separately granted reopening is a teacher action, not something this form can approve.
