# C01 — start here

The course works fully offline. A current browser is sufficient for the presentation. Node.js `v24.21.0` is required only for the canonical examples.

## Start

1. Extract the complete ZIP.
2. Run `VERIFY_PACKAGE`.
3. Open the deck with `OPEN_PRESENTATION`.
4. Do not install anything.

## Examples

`04_CANONICAL_EXAMPLES` contains all five unchanged U01 examples. Run `RUN_ALL_EXAMPLES` only after `CHECK_ENVIRONMENT` confirms Node `v24.21.0`.

## What you should be able to explain

- client/server roles;
- resource versus representation;
- URL components;
- request and response anatomy;
- methods, statuses, headers and Content-Type;
- what each item of evidence can and cannot demonstrate.
