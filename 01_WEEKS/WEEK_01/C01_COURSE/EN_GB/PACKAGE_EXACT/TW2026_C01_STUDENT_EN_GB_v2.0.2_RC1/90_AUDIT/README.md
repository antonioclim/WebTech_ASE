# C01 package identity

Release candidate: **2.0.2-rc.1**, for Week 01 English groups.

`PAYLOAD_SHA256SUMS.txt` names every protected payload file. `PACKAGE_ID.txt` is the SHA-256 of the exact manifest bytes. `VERIFY_PACKAGE` checks the identity, protected hashes and exact set, and rejects missing, added, unsafe or case-colliding paths and symbolic links.

This is an integrity check. It does not certify a browser, Windows, macOS, Word, Moodle or a classroom timing pilot. The outstanding qualification is recorded in `RELEASE_CANDIDATE.json`. Repository remediation evidence records the local checks separately.
