# C01 — începe aici

Cursul funcţionează complet offline. Pentru simpla prezentare este suficient un browser actual. Node.js `v24.21.0` este necesar numai pentru exemplele canonice.

## Pornire

1. Extrage complet ZIP-ul.
2. Rulează `VERIFY_PACKAGE`.
3. Deschide prezentarea cu `OPEN_PRESENTATION`.
4. Nu instala nimic.

## Exemple

Directorul `04_CANONICAL_EXAMPLES` conţine toate cele cinci exemple U01, nemodificate. Rulează `RUN_ALL_EXAMPLES` numai după ce `CHECK_ENVIRONMENT` confirmă Node `v24.21.0`.

## Ce trebuie să poţi explica

- rolurile client/server;
- resursă versus reprezentare;
- componentele URL;
- anatomia cererii şi răspunsului;
- metode, statusuri, headere şi Content-Type;
- ce poate şi ce nu poate demonstra fiecare probă.
