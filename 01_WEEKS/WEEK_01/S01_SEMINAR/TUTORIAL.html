P02 — Precise greeting resource

Edit only: CLASSROOM_RC6/targets/p02.mjs. Interface: greeting(method, pathname).

Reason about the boundary

The decision order is raw path recognition → method → decoding the authorised segment → trimming → value and envelope. Path recognition happens before decoding the name. A literal extra path segment must not accidentally become part of a valid resource. Once exactly one encoded segment matches, decode and trim it. Invalid encoding and an empty decoded name are input errors; a method other than GET on a matched route is a method error.

Input or conditionExpected contract behaviour
