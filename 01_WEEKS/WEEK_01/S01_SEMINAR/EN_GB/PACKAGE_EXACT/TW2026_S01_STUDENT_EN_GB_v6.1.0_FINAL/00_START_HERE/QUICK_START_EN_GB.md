# S01 quick start — use the full guide for every critical action

1. In File Explorer or Finder, extract the ZIP into a fresh folder. Expected root: 00_START_HERE, 02_PROJECTS, tools and VERIFY_PACKAGE. STOP if still browsing the ZIP.
2. Open the guide with OPEN_BEGINNER_GUIDE. Expected: S01 v6.1 guide and the 26-step route. If the launcher fails, open its HTML target directly. A browser source viewer is not the running guide.
3. Run VERIFY_PACKAGE. Expected: PASS_PACKAGE_INTEGRITY_EXACT_SET and the real PACKAGE_ID. On failure, preserve the message and re-extract. Never edit the manifest to obtain PASS.
4. Run CHECK_ENVIRONMENT. Expected exact Node.js v24.21.0/npm11.19.0. A mismatch stops the student route. No installer is run.
5. Open the extracted root in VS Code through File > Open Folder. If Workspace Trust appears, inspect the source and follow institutional policy. Do not bypass Restricted Mode blindly.
6. Select Terminal > New Terminal. Use the platform commands printed in the guide. Keep the two prospective predictions before starting the experiment.
7. VERIFY_INITIAL_STATE must report P01 baseline2/objective1 expected assertion/regression3 and P02 baseline2/objective2 expected assertions/regression4. A parse error is never an expected assertion.
8. START_PROJECT_1 prints a loopback URL. Ctrl-click or Cmd-click that URL. Open Network on that local tab, not on Gemini or another tab. Click Run investigation once after clearing the log. Record exactly three lesson requests and interpret the headers.
9. Edit only P01 case-report.json and run TEST_PROJECT_1. The updated report must enter complete mode and pass all six named tests.
10. START_PROJECT_2 starts the second server. Preserve the second prediction before implementing the path greeting. Edit only application-handler.js and use TEST_PROJECT_2. Eight named tests must pass when complete.
11. Independently test the encoded-space, blank-name and extra-segment cases. Read the bounded Gemini prompt, remove sensitive data, send once and audit one claim. Do not ask for the whole assessed module.
12. At T60 stop technical content, save the real state and run STOP_SERVERS then STATUS_SERVERS. Complete the form outside the kit, reconfirm privacy/declaration and export one PDF. Check the final paragraph and upload only after the Moodle route is available.
