# S01 Moodle upload — one private PDF

The route is generic and has not been verified on online.ase.ro in this build. Labels vary by Moodle version, language and institutional settings.

1. Finish FORM_S01_EN_GB locally. Confirm all required fields, then privacy and the individual declaration. Editing again clears these confirmations. Save a JSON backup outside the kit.
2. Select Export / print PDF. In the browser print dialog choose Save as PDF, Microsoft Print to PDF or the platform equivalent. Use TW2026_S01_GROUP_Surname_Firstname.pdf, for example TW2026_S01_1042_Popescu_Ana.pdf. Do not use an institutional account screenshot as evidence.
3. Open the saved PDF. Inspect every page and the final paragraph of the longest answer. STOP if anything is missing, clipped or private. Correct the form and export again.
4. Open the official institutional site in a new browser tab. Sign in using the normal permitted route. Do not copy login details into this kit or Gemini.
5. Open the correct Web Technologies course and Week 1. Select the S01 HTTP Detective + Tiny HTTP Server Assignment. STOP if the title/course is wrong.
6. Select Add submission or its equivalent. Drag the one PDF into the file area or select it through the file picker. Wait until the exact filename is displayed and the progress indicator ends.
7. Select Save changes. Return to the Assignment status page. A saved draft is not necessarily final.
8. If Submit assignment is displayed, select it and confirm any required submission statement. Do not repeatedly click it while the page is loading.
9. Reopen the status page. Verify final status, filename and timestamp. STOP if it says Draft where a final submit button is enabled, if a wrong file is shown or if the upload failed. Ask the teacher with a redacted error, not your credentials.
10. Keep your local PDF and JSON backup. Do not add Moodle submissions or backups to the immutable kit folder or GitHub.
