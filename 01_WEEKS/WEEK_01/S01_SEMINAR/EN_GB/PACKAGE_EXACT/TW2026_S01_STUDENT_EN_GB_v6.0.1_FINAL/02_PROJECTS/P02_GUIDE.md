# P02 — Tiny HTTP Server

Use the kit launchers from the package root. Do not run `npm install`.

Modify only:

```text
P02_TINY_HTTP_SERVER/src/application-handler.js
```

Run the tests with `TEST_PROJECT_2`, start the server with `START_PROJECT_2` and stop the server with `Ctrl+C`. The integrated interactive guide provides the exact code, probes and expected outputs.
