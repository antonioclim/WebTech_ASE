# Moodle submission guide — S01

## File to submit

Submit exactly one PDF generated from the official S01 form.

```text
TW2026_S01_GROUP_Surname_Firstname.pdf
```

Replace `GROUP` with the actual group number. Example:

```text
TW2026_S01_1042_Popescu_Ana.pdf
```

## Before opening Moodle

1. Complete every required field in English.
2. Validate the HTML form or review the DOCX form.
3. Export or print the form to PDF.
4. Open the PDF and check every page.
5. Confirm that no password, token, API key, session cookie, private Moodle data or unnecessary personal data is visible.
6. Confirm the exact filename.

## Steps in online.ase.ro

1. Open `online.ase.ro` in the browser.
2. Sign in with the permitted account.
3. Open the **Web Technologies** course.
4. Open the **Week 1** section.
5. Select the Assignment whose title contains **S01**.
6. Select **Add submission**.
7. Select the file area or drag the PDF into it.
8. Wait until the exact filename is visible.
9. Select **Save changes**.
10. Return to the Assignment page.
11. If **Submit assignment** is displayed, select it and confirm.
12. Check the submission status, filename and timestamp.

## STOP conditions

Stop and correct the submission when:

- the status still says **Draft**;
- the filename is wrong;
- more than one file is attached;
- the PDF cannot be opened;
- the PDF contains sensitive information;
- the submitted file is not the official S01 form.

Do not upload the complete project, `node_modules`, the original ZIP or the complete Gemini conversation.
