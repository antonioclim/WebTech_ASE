Seminar 1 — complete click-by-click guide

This guide assumes no prior experience with VS Code, terminals, Developer Tools, Network requests, Gemini or Moodle submission.

1. Read this first

Your screenshot is Firefox, not Chrome. The labels Inspector, Debugger, Style Editor and Storage identify Firefox Developer Tools. It is also recording chatgpt.com, which is the wrong page for S01. For the exercise, the browser tab must show an address beginning with http://127.0.0.1:.

Non-negotiable rules

  • Do not work from inside the ZIP file.
  • Do not run npm install. The S01 projects have no external dependencies.
  • Use Node.js v24.21.0 and npm 11.19.0.
  • In P01, modify only 02_PROJECTS/P01_HTTP_DETECTIVE/case-report.json.
  • In P02, modify only 02_PROJECTS/P02_TINY_HTTP_SERVER/src/application-handler.js.
  • A timeout, crash or frozen process is not an expected pedagogical failure.
  • Gemini is a reviewer, not evidence. Verify its claims with tests or HTTP observations.

8. Project 2 — Tiny HTTP Server

16

  3. Expand src.

17

Implement the path-based greeting route

Replace only the TODO branch with the following code.

const greetingPrefix = '/api/greetings/'; if (request.method === 'GET' && url.pathname.startsWith(greetingPrefix)) { const encodedName = url.pathname.slice(greetingPrefix.length); if (encodedName.includes('/')) { return false; } const name = decodeURIComponent(encodedName).trim(); if (!name) { sendJson(response, 400, { error: 'name_required' }); return true; } sendJson(response, 200, { message: `Hello, ${name}!`, source: 'path' }); return true; }

Save the file with Ctrl+S.

9. Perform the Gemini audit click by click

21

Open a new Gemini chat

  1. Open a new browser tab.
  2. Click the address bar.
  3. Type gemini.google.com.
  4. Press Enter.
  5. Sign in only with the account permitted for the course, if required.
  6. Click New chat in the top-left area. If it is hidden, open the menu first.

22

Paste the complete audit prompt

Use the copy button. Read the prompt once before sending it.

Analyse only the deliberately flawed patch for: GET /api/greetings/<name> For every claim, provide: 1. classification: observed, inferred or unknown; 2. the minimum counterexample; 3. the relevant test or HTTP observation; 4. a verdict: accepted, rejected, partly accepted or unknown; 5. the limitation of the available evidence. Do not modify the tests. Do not propose changes outside src/application-handler.js. Do not extend the route contract. Required contract: - GET /api/greetings/Ada returns status 200; - GET /api/greetings/Ada%20Lovelace decodes and trims the name; - GET /api/greetings/%20%20 returns status 400 with name_required; - GET /api/greetings/Ada/extra must not be accepted by this route; - the successful response is: {"message":"Hello, <name>!","source":"path"} Deliberately flawed patch: if (url.pathname.includes('/api/greetings/')) { const name = url.pathname.split('/').pop(); sendJson(response, 200, { greeting: `Hello, ${name}!` }); return true; } Claim: “The patch covers every name, including encoded spaces and empty names.” Return a table with these columns: Claim | Observed / inferred / unknown | Minimum counterexample | Relevant test or evidence | Verdict | Limitation
  1. Click inside the Gemini prompt box.
  2. Press Ctrl+V.
  3. Check that the complete flawed patch is present.
  4. Click the Send arrow once.
  5. Wait for the response to finish.
Gemini is not the authority. Its answer becomes useful only after you verify it against a test, an HTTP response or a reproducible counterexample.
23

Verify the Gemini response instead of copying it

At minimum, the audit should detect that the flawed patch:

  • uses includes() instead of a precise prefix contract
  • hides extra path segments through split('/').pop()
  • does not call decodeURIComponent()
  • does not trim the decoded name
  • returns 200 for an empty name
  • uses the wrong response key greeting
  • omits source: 'path'

Record the verdict, evidence and limitation in the S01 form.
