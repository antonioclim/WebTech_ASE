# Load and Failure Probe Reference

Run `npm test` for deterministic and real-loopback gates or `npm start` for a six-request example. The probe bounds request count and concurrency, measures through JSON body consumption, separates application/transport/timeout outcomes, and reports nearest-rank p95.

This is a small reproducible teaching probe. Its result describes only the supplied scenario and machine; it is not a production capacity or SLO claim.
