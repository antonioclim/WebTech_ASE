S14 — Production Evidence and Regression Closure

Scope

S14 closes the Regression Harness portfolio, applies a Production Evidence Review to the student's own project and records one bounded demonstration and defence. P02 remains optional advanced work. P04 remains a separate assessment-bank task.

Sixty-minute route

  1. Record the exact package, actual runtime, execution scope and unresolved gates.
  2. Close the unit/integration/HTTP Regression Harness matrix and persisted follow-up evidence.
  3. Attribute four seeded mutations, repeat the run and record zero-resource diagnostics.
  4. Apply a pass/fail/unknown Production Evidence Review to the student's own project.
  5. Demonstrate one bounded behaviour and state its evidence class and limitation.
  6. Defend one sampled claim, preserve one actual bounded Gemini exchange and record AI assistance.
  7. Save one honest PDF draft and stop at minute 60.

Evidence rules

A green test run is not a release certificate. Unknown tool, runtime or deployment evidence remains UNKNOWN. Do not include credentials, tokens, cookies, secrets, raw bodies or unnecessary personal data. No upload, release, deployment or final tag is authorised by this package.

Submission

One private S14 Assignment receives one reviewed PDF. No C14 Assignment exists. The final PDF must distinguish actual execution from source analysis, synthetic models and pending platform evidence.

Evidence source, execution, platform and publication remain separate.
