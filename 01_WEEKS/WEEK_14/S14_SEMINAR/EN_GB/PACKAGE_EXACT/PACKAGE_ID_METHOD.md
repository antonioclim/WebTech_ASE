# Package identity method

Object: WEBTECH_ASE_S14_STUDENT_EN_GB_v1.1.0_PUBLIC

`SHA256SUMS.txt` lists every regular file in this package except itself and `PACKAGE_ID.txt`, sorted by UTF-8 relative path. `PACKAGE_ID.txt` is the SHA-256 digest of the exact UTF-8 bytes of `SHA256SUMS.txt`. ZIP identity is recorded externally in a sidecar and receipt.
