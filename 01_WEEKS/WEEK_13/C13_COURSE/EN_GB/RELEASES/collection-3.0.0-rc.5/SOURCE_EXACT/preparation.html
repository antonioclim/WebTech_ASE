C13 — Preparation and transfer

Before the course

Do not install packages or start the canonical example servers. Read the Unit 13 introduction and record a prediction for each question.

  1. A persisted JSON record has the correct key but an unsupported version. Which boundary decides whether to migrate or remove it?
  2. A large ArrayBuffer is sent to a Worker. When would transfer be preferable to cloning?
  3. A Service Worker is active but navigator.serviceWorker.controller is null. Which facts are established and which are not?
  4. An iframe message has the expected payload but arrives from a different Window. Which check rejects it?
  5. A replaced frame sends a late ready message. Which lifecycle identifier rejects it?

During C13

For each observation, label its evidence class: SOURCE, FIXED_MODEL, JAVASCRIPT_HELPER, FAKE_ENDPOINT, REAL_BROWSER or PLATFORM. Do not convert historical README validation claims into current execution evidence.

Do not copy cookies, tokens, credentials or private institutional data into notes. Do not start Worker, Service Worker or multi-origin examples merely because their README contains commands.

Transfer to S13

P01 is the central implementation. The assessed path is:


student/src/worker-client.js

Prepare a lifecycle table for synchronous reply, reversed completion, progress, abort, worker failure and disposal. Each row should identify settlement, pending cleanup, timer cleanup, listener cleanup and whether later analysis is allowed.

P02 contributes a guided lifecycle trace for registered, ready and controlled states. P03 remains optional advanced.

At the end of S13, launch the Regression Harness portfolio by recording its package identity, target behaviour, initial unit/integration/HTTP matrix, one mutation candidate and outstanding work. Do not claim completion in the five-minute hand-off.

Bounded Gemini critique

Ask Gemini about one sanitised Worker lifecycle, Service Worker control or message-trust claim using a minimal excerpt. Preserve only the relevant actual response excerpt, then verify independently. Use ACCEPTED, REJECTED, PARTIALLY ACCEPTED or UNKNOWN. UNKNOWN is not a pass for the implementation.

STOP condition

At minute 60, save an honest draft. Record unfinished P01 work, pending real-browser evidence and outstanding Regression Harness work. The reserved 30 minutes are not overflow.

60-minute content limit. Source, model, browser and platform evidence remain distinct.
