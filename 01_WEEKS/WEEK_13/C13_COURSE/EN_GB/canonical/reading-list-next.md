# Reading list for the next lecture — Lecture 14 — Testing, Observability, Performance and Production Review

Complete these readings before Lecture 14 — Testing, Observability, Performance and Production Review.

- [Node.js: Test runner](https://nodejs.org/api/test.html) — structure executable checks, suites, hooks, and test isolation.
- [web.dev: Web Vitals](https://web.dev/articles/vitals) — ground client performance claims in user-centered metrics.
- [OWASP: Logging Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html) — design useful security and operational events without leaking sensitive data.
- [npm Docs: Auditing package dependencies](https://docs.npmjs.com/auditing-package-dependencies-for-security-vulnerabilities/) — interpret dependency findings and the limits of automated remediation.
