# Evidence and acceptance boundaries

This v1.2.0 corpus is a Phase 2 local production candidate. Final local admission requires Phase 3 independent hostile review and fresh extraction replay. It is not published or owner accepted.

Pure Node fixtures exercise protocol models. They do not execute browser Worker or Service Worker contexts. Document rendering uses local projections and is not native Microsoft Word acceptance. Static interface diagrams are illustrations, not captures of a student session.

Open gates are the exact Node/npm pins, actual browser Worker/oracle/responsiveness, Service Worker registration/control/task GET, HTTP integration, native Windows/macOS/Linux application routes, browser file storage/clipboard/focus/print and all 15 prescribed viewport/scale combinations, native Word, an actual Gemini Web exchange, the institution's Moodle settings, novice cohort timing, owner acceptance and publication.

No installation, browser download, server start, native browser start, live Gemini exchange, Moodle mutation, remote write or GitHub Actions run is performed during this local production phase. Unknown results remain null or visibly pending. A timeout, crash or resource leak is a failure/block and cannot be classified as an intentional starter assertion failure.
