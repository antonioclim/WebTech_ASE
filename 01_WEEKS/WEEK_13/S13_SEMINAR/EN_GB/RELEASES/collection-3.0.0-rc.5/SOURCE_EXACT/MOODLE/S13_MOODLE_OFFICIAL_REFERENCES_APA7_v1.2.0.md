Assignment settings describes file submissions, accepted file types, course upload limits and configurable submission statements. Using Assignment explains that saving a file may leave draft status when a separate submit step is required. Rubrics describes criteria levels, the activity maximum and score normalisation. These documentary statements support the proposed route while the 26 institution-specific settings remain unknown.
