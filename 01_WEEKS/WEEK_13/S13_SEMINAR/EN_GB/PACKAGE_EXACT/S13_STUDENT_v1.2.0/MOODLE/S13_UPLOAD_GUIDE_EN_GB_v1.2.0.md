# S13 single PDF upload route

Use this route only when the teacher has supplied the actual institution-approved course and S13 Assignment. Moodle version, activity URL, deadline, alias policy, file-size limit and final-submit behaviour have not been observed in this kit. Confirm them on the actual activity. No live Moodle configuration or student submission was performed during local production.

1. Open your completed evidence form from the extracted Student kit. Export a JSON backup before printing. Review unresolved required evidence. Keep an honest draft if work is pending; do not rename it a verified final result.
2. Review privacy after the last material edit. Prepare the current print text, then open print preview. Choose A4 and a readable scale. Check every section, page break and the very last line. In a browser choose Save as PDF or its actual equivalent. In Word use the actual PDF export route. Native browser and Word acceptance require actual verification.
3. Replace CODE in `TW2026_S13_CODE.pdf` with the institutionally approved student code or alias. Open the saved PDF itself. Check that it is readable, individual, redacted and complete. A declaration in the form cannot prove this file was reviewed.
4. Log in through the institution-approved route. Open the correct course and week, then the actual S13 Assignment. Check its title, deadline, timezone, accepted type and maximum size. C13 has no Assignment. Stop if the course or activity differs.
5. Choose Add submission or the equivalent observed label. Use the file picker or drop area to select the single reviewed PDF. Do not upload a project ZIP, source directory or node_modules. Wait for the actual upload to finish and read the displayed filename.
6. Choose Save changes or its actual equivalent. If the activity requires Submit assignment and a submission statement, use that route and confirm truthfully. Read the actual statement first. Saving changes may leave a draft.
7. Return to the activity status panel. Read the real final status, filename and timestamp. If it still says Draft or an upload error, stop and follow the actual activity instructions. Do not treat a progress bar, PDF print or local declaration as final submission proof.
8. Record the actual final status and a private evidence locator. Avoid account screenshots with unnecessary personal data, internal URLs, cookies or tokens. The form may record `SUBMITTED_UNVERIFIED`; that local report does not certify institutional acceptance.

If any step is blocked, keep the local PDF and JSON backup, record the precise reason and contact the teacher through the approved route. No automatic retry, account login or remote transmission occurs from this kit.
