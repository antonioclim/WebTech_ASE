# Composable Shell — Reference

```sh
npm install
npm test
npm start
```

Open `http://127.0.0.1:4212/?selftest=1`. The shell embeds catalog `:4213` and details `:4214`, rejects a forged-origin selection, routes a real selection through shell URL/API state, then reloads the catalog at generation 2 before reporting `data-selftest="pass"`.

This visible boundary is not authentication or a production microfrontend framework.

Run `npm run test:browser` with Chrome/Chromium available for the real lifecycle gate. Set `CHROME_BIN` if the executable is not named `google-chrome`.
