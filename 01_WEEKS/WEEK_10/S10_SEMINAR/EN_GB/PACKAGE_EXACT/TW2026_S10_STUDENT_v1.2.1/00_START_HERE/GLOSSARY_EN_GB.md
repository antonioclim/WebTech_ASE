# S10 glossary

- **Authority** — the component or system that owns the value and its update rules.
- **Context** — a React mechanism that lets descendants read a provided value without prop-passing through every intermediate component.
- **Reducer** — a pure transition function from previous state and action to next state.
- **Dispatch** — the function that sends an action to the reducer.
- **Shared state** — state needed by multiple distant consumers during the same provider lifetime.
- **Local state** — state owned by a specific component or interaction.
- **Derived value** — a value calculated from authoritative inputs rather than stored again.
- **Provider isolation** — two mounted providers maintain independent state.
- **Capability gate** — a mandatory requirement that makes a candidate eligible or ineligible before cost comparison.
- **ADR** — Architecture Decision Record: context, constraints, alternatives, evidence, decision and limits.
- **Evidence class** — SOURCE, MODEL, REACT_TEST, REAL_BROWSER or NOT_EXECUTED.
