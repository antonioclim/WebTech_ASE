# S10 real React companion lane · scoped classroom shell

The framework is actual React 19.2.8 with the reviewed retained dependency graph. The supplied shell owns controlled selection, result and error state. You author the bounded functions in `../student/`; you do not author this supplied shell. JSDOM tests exercise real React rendering, events and state publication. They do not establish native browser behaviour, a complete full project, actual HTTP/Worker/Redux behaviour or measured classroom feasibility.

Dependencies must be provisioned from this lockfile before the 60-minute meeting. From this REACT directory use `npm ci` for provisioning, then `npm run test:baseline`, `npm run test:objective` and `npm run build`. The untouched starter is expected to pass the one shell baseline and fail its three named objective assertions. Work completion requires those same objective assertions to pass after your own bounded functions are implemented. Record actual commands and output; missing tools, import errors, crashes and timeouts are not expected objective assertions. A native page route may use `npm run dev`; observe its actual loopback URL and stop the process you started afterwards. No server is started automatically. The Node classroom checker remains a separate dependency-free scope.
