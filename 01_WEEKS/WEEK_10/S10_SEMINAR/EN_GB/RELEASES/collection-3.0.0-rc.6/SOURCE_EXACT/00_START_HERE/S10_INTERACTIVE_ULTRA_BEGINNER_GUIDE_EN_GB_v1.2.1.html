Reveal-answer checks

Why split state and dispatch contexts?

It lets components request only the context they use. It does not guarantee zero rerenders caused by parents or other state.

Does two cloned initial states prove provider isolation?

No. Provider isolation requires two mounted providers and an action that changes only one instance.

Must P02 or full P03 comparator code be completed?

No. P02 and full comparator implementation are optional. The State ADR is required.
