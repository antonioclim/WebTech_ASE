# S10 quick start

1. Extract the ZIP.
2. Open `OPEN_BEGINNER_GUIDE`.
3. Run `VERIFY_PACKAGE`.
4. Run `CHECK_ENVIRONMENT`; stop on runtime or dependency mismatch.
5. Record two predictions before editing.
6. Run `VERIFY_INITIAL_STATE` only in a provisioned environment.
7. Edit only the P01 assessed file.
8. Use `TEST_P01` and `VERIFY_WORK_RESULT`.
9. Complete the State ADR and bounded Gemini audit.
10. Export one PDF and verify its final Moodle status.
