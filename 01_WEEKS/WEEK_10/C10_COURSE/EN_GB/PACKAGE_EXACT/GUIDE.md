# C10 reading guide

Open index.html, then course.html. Use Previous/Next, the screen selector, unmodified arrow/Page keys, Home/End or Reading mode. Keys typed in controls are not navigation shortcuts. Text can be adjusted from 40% to 160%; larger content flows vertically instead of shrinking to conceal overflow. Print requests your browser print dialogue; it does not certify a saved PDF.

Read the complete handout and preparation note. The model lab requires a prediction before Run, clears stale results when inputs change and labels exports as model output. It saves no student record automatically and imports no data. Application execution is separate; consult RUN_EXAMPLES.md.

P01 is central in full, P02 optional advanced and a state ADR is required from P03. No extra C10 Assignment exists. Stop at minute 60.
