# Reading list for the next lecture — Lecture 11 — Authentication, Authorization and Web Security

Complete these readings before Lecture 11 — Authentication, Authorization and Web Security.

- [OWASP: Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) — review identity proof, credential handling, and authentication defenses.
- [OWASP: Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) — design deny-by-default, server-side authorization decisions.
- [OWASP: Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) — connect session identifiers, cookies, rotation, and invalidation.
- [MDN: Cross-Origin Resource Sharing](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS) — reason precisely about origins, preflight, response sharing, and credentials.
