# Rule Engine

Do not run `npm install`: this project has no external dependencies. Run the focused checks, `npm run evaluate` and `npm test`. Implementations belong only in `src/rule-engine.js`.

Use the project-level README for the staged AI workflow. Student work begins with a no-edit analysis of rule shapes, own properties, closure capture, recursion and short-circuiting, followed by a bounded one-file change and independent verification.
