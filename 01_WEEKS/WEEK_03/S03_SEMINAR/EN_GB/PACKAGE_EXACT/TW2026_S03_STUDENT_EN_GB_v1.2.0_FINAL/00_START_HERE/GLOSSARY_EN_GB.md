# S03 glossary

- **ZIP:** a compressed container that must be extracted before work.
- **Extracted folder:** the writable working copy produced from the ZIP.
- **VS Code:** the code editor used to inspect and edit the permitted source file.
- **Terminal:** a text interface where commands run in a working directory.
- **Working directory:** the folder from which a command resolves relative paths.
- **CLI:** a command-line interface.
- **Fixture:** synthetic input used by a bounded test or demonstration.
- **Own property:** a field stored directly on an object rather than inherited through its prototype.
- **Coercion:** an implicit or explicit conversion from one type to another.
- **Projection:** creation of a new record shape containing selected fields.
- **Mutation:** an in-place change to caller-owned data.
- **Aliasing:** two references pointing to the same object.
- **TAP:** the deterministic text format emitted by the Node test runner in this package.
- **Assertion:** a precise expected-versus-actual check.
- **Runtime:** the Node.js and npm environment executing the project.
- **Verdict:** ACCEPTED, REJECTED, PARTIALLY ACCEPTED or UNKNOWN after independent checking.
