# S03 distribution identity

SHA256SUMS.txt lists every file in this distribution except SHA256SUMS.txt and PACKAGE_ID.txt, sorted by relative POSIX path. Each UTF-8 LF-terminated line is the lower-case SHA-256 hex digest, two spaces and the exact relative path. PACKAGE_ID.txt contains SHA-256 of the exact manifest bytes followed by one LF. The external .zip.sha256 sidecar hashes the exact ZIP and names that exact ZIP file.

This identity describes the untouched distribution, not a working copy after the permitted student edit. Keep the original ZIP. The project gate checks the one-file edit boundary separately. Hash integrity is not authorship, code correctness, runtime acceptance or permission to publish. The teacher package contains the read-only package verifier; it is not a student Python prerequisite.
