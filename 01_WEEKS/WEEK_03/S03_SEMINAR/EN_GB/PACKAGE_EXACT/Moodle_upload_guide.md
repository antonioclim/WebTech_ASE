# Moodle upload guide

## Before you upload

Use the Assignment named TW2026 — S03: Dataset Transformer CLI and Generated-Code Audit on your actual course at online.ase.ro. Read its live deadline and size cap. This kit has not configured the site. Complete P01 and the required P03 portfolio in one individual form. Optional P02 work is not required for the standard maximum mark.

## Save the source draft

In evidence.html choose Export JSON and confirm that the file appears in your chosen folder. Local browser storage is optional and may vary when the form is opened with a file URL; a visible save error means it was not saved. Keep the JSON private as a working draft, not as the assignment submission. With the DOCX alternative, save the edited document privately.

## Create the PDF

In the HTML form choose Check final fields, correct the highlighted omissions and renew the declaration after importing. Choose Print final PDF. In the browser print dialogue select its PDF destination (label varies by browser/OS), use A4 and inspect every preview page. The generated filename is a suggestion: the browser may not enforce it. Copy it exactly and avoid a doubled .pdf extension. With DOCX use the word processor’s PDF export and apply the same name.

## Inspect the saved file

Open the saved PDF outside the editor. Check identity, all eight sections, visible evidence excerpts, verdicts and limitations. Ensure it is not marked CORE DRAFT and contains your text, not the blank form. Text evidence is sufficient; screenshots are optional, need captions and do not replace commands/inputs. The HTML form does not import image files; use the DOCX version to include optional screenshots. Never upload the private teacher package, JSON draft, ZIP or a full AI conversation.

## Upload, then complete submission

In the Assignment choose Add submission, add the one PDF and save the changes. Open the uploaded file to confirm the correct content. Where the status is Draft (not submitted), choose Submit assignment and complete any required declaration. Verify Submitted for grading (or the equivalent translated status), filename and timestamp. Saved draft is not final submission. Moodle labels may differ with site version, language and settings.

## Handle a problem honestly

Wrong file: while still draft, use Edit submission, replace it and check again. After final submission, request reopening rather than repeatedly adding files elsewhere. Oversized PDF: remove unnecessary images or reduce their resolution without making evidence unreadable, then export again. Missing Gemini access or incomplete P03: preserve the draft and contact the teacher; do not claim a synthetic practice interaction was genuine. A screenshot of an error supports troubleshooting but does not prove a successful submission.
