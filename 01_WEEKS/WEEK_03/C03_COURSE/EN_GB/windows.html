Windows — open C03 without installing anything

Save the current complete collection ZIP in your chosen Downloads folder.

  1. Open File Explorer and locate the current complete collection ZIP.
  2. Right-click the ZIP and select Extract All. Choose a short destination such as D:\WTW03\C03. A student without drive D can choose a short folder on an available drive.
  3. Within the extracted collection open 01_WEEKS/WEEK_03/C03_COURSE/EN_GB. Confirm that index.html, course.html, lab.html, assets and documents are beside one another.
  4. Open index.html. If the file opens in an editor, right-click it, choose Open with and select the already installed browser.
  5. Choose Presentation. Use the visible buttons or the screen selector. The final screen synthesises the six lenses and names all three current S03 projects. The 60-minute core remains an unpiloted planning estimate.
  6. Choose Laboratory for a bounded experiment. Enter a prediction, select a variant and press Run demonstration. Export the session JSON before closing; confirm the browser saved it.
  7. Open the Word documents from documents. The browser-readable handout is available when Word is not installed. No macro is required.

Do not run HTML from the ZIP preview. Do not disable browser or operating-system protection, install a browser extension or launch an administrator shell. If an institutional policy blocks local JavaScript, use the readable handout and retain that limitation for later support. A printed explanation is not an executed test.

This is a reading route, not GitHub publication guidance. Optional existing-environment Node commands are isolated in RUN_EXAMPLES.md.
