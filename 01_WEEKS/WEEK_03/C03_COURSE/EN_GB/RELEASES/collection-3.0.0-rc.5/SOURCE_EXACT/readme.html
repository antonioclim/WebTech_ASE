Open the lesson

Extract the complete student ZIP into a short local folder. Do not open HTML while it is still inside the compressed-folder preview. Open index.html, then choose Presentation, Laboratory or Handout. Keep the folder structure together. Nothing needs to be installed for these HTML materials. No local server, CDN, login or API key is required.

On Windows, use File Explorer → right-click the ZIP → Extract All. A suitable short folder is D:\WTW03\C03. On macOS, use Finder to expand the ZIP and open the extracted index.html with your browser. On Linux, use the archive manager to extract it and then open index.html. The individual platform guides give the full route. Browser and operating-system acceptance is not inferred from the package contents; retain any discrepancy rather than declaring an automatic pass.

What to use

course.html is a self-contained 24-screen presentation with a complete minute-60 stop. It supports buttons, keyboard navigation, a screen selector, reading mode, printing and text size from 40% to 160%. Buttons or fields retain their own keyboard handling. The public handout is available as reading.html and documents/C03_HANDOUT.docx. documents/C03_PREPARATION_TRANSFER.docx distinguishes before-class, core and after-class work.

lab.html runs five bounded local demonstration families. Write a prediction before a run. Export observations to retain them; the page does not silently save them. An imported log is unverified historical text, not a fresh run. This lab does not inspect or grade S03 code. SYNTHETIC_CLAIM.txt is an explicitly authored offline practice claim, not a real Gemini conversation.

canonical/ contains the five original worked examples and their READMEs. Preserve them. canonical/package.json is a new module envelope outside those ten files. Optional Node instructions are in RUN_EXAMPLES.md; no dependency installation is required. The reference environment is Node 24.21.0 and npm 11.19.0, as specified by the course handover. A different runtime is not silently equivalent.

End of the course

At minute 60 retain one prediction, one observation, an explanation and a limitation. There is no separate C03 Moodle assignment. S03 P01 is the central seminar task, P03 is required later portfolio work and P02 is optional advanced work. Their full contract is supplied in S03, not invented here.

Integrity and sources

SHA256SUMS.txt covers every file except itself and PACKAGE_ID.txt. PACKAGE_ID.txt is the SHA-256 of the exact UTF-8 manifest bytes. Each manifest line uses hex, two spaces, a relative POSIX path and LF. The ZIP sidecar uses the exact archive filename. Public source attribution is in SOURCES.md; source-copy hashes are in CANONICAL_SOURCES.json. No teacher guide, console, assessed reference implementation or private QA is included.

No GitHub upload, GitHub Actions, Pages deployment, Release or Moodle configuration is required to read this package.
