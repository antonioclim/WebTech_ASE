Course guidance

macOS and Linux — local C03 launch

macOS

In Finder, locate WEBTECH_ASE_C03_STUDENT_EN_GB_v1.1.0_PUBLIC.zip in Downloads. Open the ZIP to expand it with the system archive utility. Move the extracted folder to a short location such as Documents/WTW03/C03. Keep assets, documents and canonical beside the HTML files. Open the extracted index.html; use Open With to choose an already installed browser if needed. Choose Presentation, Laboratory or Handout.

Linux

Use the desktop file manager to locate the ZIP. Open it with the archive manager and extract the complete contents into a short folder such as Documents/WTW03/C03. Open that extracted folder, then open index.html with the existing browser. Keep all relative subfolders together. No server, shell command or package installation is required for HTML teaching.

Shared operation

Use the presentation buttons and screen selector. Text size is 40–160%; reading mode and print offer a linear route. In the laboratory, predict before running, then export the observation JSON and confirm it is saved before closing. Importing a log does not rerun its experiments. Open the DOCX documents with an existing compatible application or use reading.html for the handout.

Do not execute from an archive preview, weaken security controls or install a framework for this course. If policy blocks local JavaScript, use the static handout while recording the limitation. There is no C03 Moodle upload. Existing-environment Node commands are optional and documented separately in RUN_EXAMPLES.md; they are not GitHub commands.

Native macOS/Linux desktop acceptance is a separate deferred gate. These instructions are not evidence that this phase tested your operating system or browser.
