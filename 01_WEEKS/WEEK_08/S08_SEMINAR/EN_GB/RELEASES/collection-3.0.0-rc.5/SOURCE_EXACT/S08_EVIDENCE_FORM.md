# S08 individual evidence form — blank v1.2.0

Full P01 and the eight-part P03 portfolio are required. P02 is optional and its absence imposes no mark cap.

Record one actual sanitised bounded Gemini claim, an independent check, a justified verdict, correction and limit. A synthetic illustration is practice and is not an automatic substitute. A selector cannot authorise or authenticate an alternative.

Use the HTML form for typed evidence or the native DOCX controls for your own text and embedded images. The blank reference PDF contains no completed answer. All 55 answer fields begin blank; the declaration begins unchecked.

One Assignment and one PDF: `TW2026_S08_GROUP_Surname_Firstname.pdf`. The deadline is set separately by the teacher. P03 full completion continues individually after the 60-minute content STOP; the meeting adds 30 minutes of logistics.

A draft JSON preserves typed answers only. Import resets declaration, privacy review, PDF review and upload preflight. No file, selector, form check or filename authenticates an observation, permission or institutional submission.

HTML printing expands all typed answers into a separate print view. Every field change clears the manual JSON fallback and any prepared print classification. Export again before copying fallback text. Candidate classification is rechecked at the print event and consumed once; browser behaviour remains unqualified until actual testing. Insert screenshots/images in the DOCX route and label them in the evidence index; a typed path alone does not embed evidence.

## Practical route

1. Open `form.html` from the extracted student folder. Read field help before typing. Keep predictions before the selected action.
2. Export a JSON draft at an appropriate point. Export, import and opt-in local saving share a 2,000,000-byte UTF-8 limit for the entire serialised draft, including envelope and escaping. An oversized export/save stops without truncating your visible answers: shorten bounded excerpts or use the DOCX route. Import requires exactly 55 known fields, valid types/options/calendar dates and the canonical UTC timestamp emitted by export; invalid UTF-8 and duplicate keys are rejected. If you edit answers while a file is being read, re-select the intended import after reviewing the current answers. Local saving is optional and belongs to this browser profile; shared machines may retain an older saved draft until you clear it.
3. Finish P01, all eight P03 parts and the bounded genuine Gemini audit. Distinguish actual checks from source reasoning, model traces and pending checks.
4. Review all evidence and privacy. For the first candidate export choose FINAL_CANDIDATE_NOT_YET_SAVED, privacy REVIEWED_NO_EXCLUDED_DATA and upload_checklist PENDING, then renew the declaration last. Editing evidence resets these review statements.
5. Use Check final-candidate preflight. Any required gap keeps the working document a draft. This structural check does not verify the truth or quality of answers.
6. Save/export one correctly named PDF. Reopen the actual saved file and inspect every page, wrapping, logs and images. Only after that review use LOCAL_PDF_REVIEWED_NOT_MOODLE_RECEIPT and PREFLIGHT_REVIEWED_NOT_MOODLE_RECEIPT, renew declaration last and regenerate/review if recording the changed statuses. No future Moodle receipt is required inside the PDF.
7. Follow `moodle/SUBMISSION_GUIDE_EN_GB.md`. Check actual submitted state, exact filename and timestamp afterwards. STOP on Draft. Saving a PDF is not submission.

Prior teacher authorisation is reviewed separately. If execution or Gemini is blocked, record the block and available evidence honestly, retain a draft and follow the agreed alternative route. Do not select an alternative to create your own permission.
