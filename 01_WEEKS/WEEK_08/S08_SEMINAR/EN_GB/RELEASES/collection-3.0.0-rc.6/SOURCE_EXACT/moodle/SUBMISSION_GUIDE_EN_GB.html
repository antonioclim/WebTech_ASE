The variants below are instructions to verify later, not observed screenshots or evidence that a live Assignment exists. The teacher supplies the actual course, Assignment name and deadline. 2. Check privacy and prepare the PDF

Review identity, date, group, environment and evidence labels. Include only the required academic identity and sanitised excerpts. Remove passwords, tokens, private links, personal account details and other people's data. Do not put credentials or a full private AI chat into the PDF.

Open `form.html` from the extracted student folder or open `S08_EVIDENCE_FORM_EN_GB_v1.2.0.docx`, the supplied blank DOCX. In the HTML route use the form's PDF/print control where present. If that control is unavailable, use the browser's Print command, commonly Ctrl+P on Windows/Linux or Command+P on macOS. In the print dialogue choose a PDF destination, commonly Save as PDF or Microsoft Print to PDF. In a Word route use its PDF export or save-as command. These UI routes have not been observed on your device during production. Do not claim native Word, browser or OS acceptance from this instruction.

Use A4 and inspect the preview. Save exactly one file using this template:

`TW2026_S08_GROUP_Surname_Firstname.pdf`

Replace GROUP, Surname and Firstname with the tokens required by your teacher. Use Firstname in the filename template, not GivenName. Keep the `.pdf` extension. Example of the naming pattern only: `TW2026_S08_1234_Example_Student.pdf`; this is not a completed student answer. Check the actual filename in the save dialogue and afterwards in the file manager. An inferred filename or a completion selector is not a saved-file check.

The companion `S08_EVIDENCE_FORM_EN_GB_v1.2.0.pdf` is a blank template, not your completed submission. The offline guide is also supplied as `S08_BEGINNER_GUIDE_EN_GB_v1.2.0.docx` and `S08_BEGINNER_GUIDE_EN_GB_v1.2.0.pdf`. Open the saved PDF itself. Check that all sections, your eight P03 fields, the bounded Gemini claim and independent check are readable. Check page breaks, clipping, captions, evidence references and the declaration. 3. Find the actual Assignment

When the teacher's submission route is available, open `online.ase.ro` through the normal institutional access route. Use your own authorised account and the institution's login workflow. The guide does not supply or request credentials. Confirm your account, course and group from the live page.

Open the teacher-designated S08 Assignment in the actual course. The label may be Assignment, Temă, a seminar title or another configured name. If the task, course, group, deadline or upload rules differ from the supplied contract, STOP and use the teacher exception route. Do not choose a similarly named C08 task: this contract requires one S08 Assignment and no second C08 Assignment.

4. Upload the saved PDF

Look for Add submission, Adaugă lucrare, Edit submission or the configured equivalent. If no upload control is available, the task is closed, not yet open, misconfigured or inaccessible; record what the page actually says and STOP. Do not invent a successful submission.

Select the file area. A supported UI may offer a file picker, an Upload a file entry, a Choose file/Browse button or drag and drop. Select the exact saved PDF from your computer. Check the displayed attachment name against `TW2026_S08_GROUP_Surname_Firstname.pdf`, with your actual tokens. Attach one PDF. No code ZIP or second C08 upload is required by this contract. Select Upload this file if the picker requires it, then Save changes or the live equivalent.

Wait for the page to finish and inspect the submission summary. Check the actual attached filename and any warning. An uploaded attachment alone does not necessarily mean submitted for grading.

5. Confirm the actual final status separately

If the summary says Draft (not submitted), În curs de elaborare, Not submitted or an equivalent, STOP: it is not a final submission. If a Submit assignment/Trimite lucrarea button is offered, read the declaration actually shown, confirm only statements you can make honestly and submit. Do not tick a declaration that is false. Return to the summary after the action completes.

If the Assignment uses a one-step workflow and no separate submission button exists, inspect the live summary rather than guessing. Confirm a status such as Submitted for grading/Trimisă spre evaluare, or the configured equivalent that explicitly represents final submission. A green control, selector choice or missing button is insufficient by itself.

Only after the final state is visible, preserve a separate local note or sanitised receipt with the actual course, Assignment, exact attached filename, final status text and the displayed timestamp including its timezone if shown. If the site does not display a timestamp, record timestamp NOT_DISPLAYED and your local observation time with timezone separately. Do not label the local clock as Moodle's timestamp. Check that the final attachment remains the correct PDF.

Do not rewrite and re-upload a correct PDF solely to add this post-submission receipt inside itself. The receipt is a separate observation made after submission. It is not an additional assessed attachment required by this contract.

6. If a check fails

Preserve the draft, the saved PDF and the actual error or status text. Record the limit without credentials or other people's data. Use the teacher-designated exception route if you cannot find the configured task, open the saved PDF, attach the correct file or observe final submission. Do not infer success, guess a deadline, create another Assignment or use a second C08 upload to bypass the issue.

You have finished this operational route only when your saved PDF is readable and the live page explicitly shows the correct final attachment and submission status. This guide itself does not establish that state.
