C08 — Launch and use guide

1. Extract the complete package

On Windows, save the student ZIP, right-click it and use Extract All into a new, short folder, for example D:\WTW08C. Open that folder in File Explorer and double-click index.html. On macOS, expand the ZIP in Finder and open index.html in the extracted folder. On Linux, use the graphical archive manager to extract into a new folder and open index.html with a browser. Preserve every relative folder; do not move lab.html away from assets.

The ordinary lesson route does not use a terminal, server, account, React installation or CDN. Keep teacher/private archives separate. This guide is for local teaching use, not GitHub publication.

2. Navigate and read

Open the lesson. Use Previous, Next or the Screen selector. ArrowRight/PageDown and ArrowLeft/PageUp navigate; Home and End go to the endpoints. Shortcuts deliberately do nothing while typing in inputs, text areas or contenteditable regions and do not hijack links, buttons, selects or summary controls. Modifier shortcuts remain available to the browser.

Use Text to choose 40–160%. Content remains in normal document flow; scroll when needed instead of expecting a fixed-height screen to hide overflow. Reading mode shows every screen. Print all applies the print layout to all screens. Inspect your local print preview and the saved output before claiming a PDF exists. No browser or Word-native acceptance is inferred from the production QA.

The final screen is the planned minute-60 stop. Its presence does not prove elapsed time. The remaining 30 minutes are not a buffer.

3. Use the model laboratory

Select a scenario and type a short prediction before Run model. Its text is not evaluated as code and is not graded. The output states MODEL_OUTPUT_NOT_ACTUAL_REACT_EVIDENCE. T/F/K/E are laboratory prefixes; source examples use SOURCE:01–05. The E scenarios contain logical event order, not real network timing.

Export model note requests a local text download only. Check the saved file yourself. The page cannot confirm the file exists. A changed prediction invalidates the previous export binding. No autosave, import or external transmission occurs. Clear this page draft intentionally removes the current prediction and result; closing the page loses unsaved text.

This is not the S08 evidence form. Do not pass a model result off as a React, browser or Gemini observation. Missing access is PENDING, not a manufactured transcript or successful test.

4. Inspect exact React/Vite examples separately

See RUN_EXAMPLES.md. The source READMEs contain historical npm install and validation claims; they do not supersede this guide. Source files, package.json and package-lock.json are copied unchanged. The source pins are not a claim of current availability or installation.

Do not double-click a canonical index.html and call the resulting module failure a React test. Its absolute module path is a Vite application route. A real run requires the correct project-local dependencies and the reference environment separately provisioned by the teacher. Missing prerequisites are an environment block, not a pedagogical assertion failure. No package manager command is required to view this lesson.

5. Transfer and submission

Use the preparation document and GEMINI_PROMPT.txt for one bounded critique. Keep only the relevant prompt, claim, independent check, verdict, correction and limit. Do not upload complete conversations or private information. SYNTHETIC_CLAIM.txt is labelled practice, not an actual exchange.

The subsequent S08 package supplies the full P01 implementation route, required P03 portfolio and optional P02 consolidation. Unfinished work at minute 60 remains a draft and continues before the teacher-set deadline. This C08 package does not invent a deadline or create a second Assignment.

Source/model/actual execution are distinct. This local candidate is not a publication authorisation.
