# C08 — macOS/Linux

Extract the complete package and open index.html for the ordinary HTML route. From the C08 EN_GB directory use `sh CHECK_ENVIRONMENT.sh`, `sh RUN_ALL_EXAMPLES.sh` or [the exact guarded Node commands](RUN_EXAMPLES.md). ALL runs three neutral Node sources, not all canonical React apps.

The conditional React lane uses already prepared project-local dependencies and preserves package/lock files. Use the actual dev URL and stop only your own process with Ctrl+C. A Linux Node observation does not certify macOS, native controls or saved PDF behaviour.
