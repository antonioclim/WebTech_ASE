## Preparation questions

What does a component return? Why is that not the same as appending a DOM node? Trace the topic title and summary through example 01. Predict what would change if a card receives new props. Do not call this prediction a browser observation.

Explain why the collection need not change. The laboratory T01/T02 uses a bounded model of this distinction; it does not run React.

## Evidence matrix for transfer

| Question | Minimum useful witness | What the witness does not establish |
| --- | --- | --- |
| Is the task transition immutable? | Input and next value plus retained/changed references | React's actual DOM work |
| Does filter-only work rewrite storage? | Real call trace under stated mounting conditions | Universal storage behaviour |
| Does a draft follow its record? | A real edit then prepend with IDs visible | Correctness of all key choices |
| Can late old work overwrite new work? | Named loader, guards and settlement order | Every network cancellation case |
| Is add-after-reload identity safe? | Exact persisted fixture and actual reload trace | Security or global uniqueness |
