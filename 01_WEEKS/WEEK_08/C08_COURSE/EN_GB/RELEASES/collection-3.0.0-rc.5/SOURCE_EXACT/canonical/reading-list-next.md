# Reading list for the next lecture — Lecture 09 — Routing, Forms and Full-Stack React

Complete these readings before Lecture 09 — Routing, Forms and Full-Stack React.

- [React Router: Routing](https://reactrouter.com/start/declarative/routing) — define route trees, nested routes, parameters, and links.
