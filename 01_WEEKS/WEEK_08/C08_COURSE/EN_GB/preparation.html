Preparation questions

What does a component return? Why is that not the same as appending a DOM node? Trace the topic title and summary through example 01. Predict what would change if a card receives new props. Do not call this prediction a browser observation.

In example 02, toggle task 1 in the supplied two-record fixture. Predict the new remaining count and identify which object identities should be preserved. Then change only the filter. Explain why the collection need not change. The laboratory T01/T02 uses a bounded model of this distinction; it does not run React.

Choose one laboratory scenario. Record its identifier and your prediction before selecting Run model. The input box checks only that you supplied text. Use three retrieval pauses in the lesson: after component ownership, after identity and before the minute-60 stop. Answer with a mechanism, a witness and a limitation rather than a memorised slogan. You are not required to expose an account, a complete AI conversation or private code in order to participate.
