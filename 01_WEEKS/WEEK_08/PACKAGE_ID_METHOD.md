# Exact wrapper identity

SHA256SUMS.txt covers every regular file except itself and PACKAGE_ID.txt. Lines use lowercase SHA-256, two spaces, the relative POSIX path and LF, sorted by path. PACKAGE_ID.txt is SHA-256 of the exact manifest bytes followed by LF. The external ZIP hash is recorded only in an external sidecar/receipt. Nested source packages keep their own methods and bytes. Integrity does not qualify applications, observations or publication. This is not a repository FINAL identity.
