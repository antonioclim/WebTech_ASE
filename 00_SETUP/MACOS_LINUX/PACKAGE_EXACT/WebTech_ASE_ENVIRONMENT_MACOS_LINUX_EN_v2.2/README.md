# WebTech_ASE environment kit

This student-facing kit checks the environment required by the Web Technologies module.
It does not install software, change persistent system settings or access GitHub or Gemini accounts.

Required Day 0 baseline:

```text
Node.js v24.21.0
npm 11.19.0
Git
VS Code Stable
Prettier and ESLint VS Code extensions
Chrome, Edge or Chromium
verified GitHub account with 2FA
Gemini Web access
```

Start with `QUICK_START.md`. Run the integrity verifier before the preflight.
