# Install Node.js v24.21.0 on Linux

Do not accept an arbitrary distribution version. Use an approved version manager or the matching official binary.
Check `uname -m` before choosing x64 or arm64.

Verify:

```bash
node --version
npm --version
command -v node
command -v npm
```

Required result: `v24.21.0` and `11.19.0` from the same installation route.
