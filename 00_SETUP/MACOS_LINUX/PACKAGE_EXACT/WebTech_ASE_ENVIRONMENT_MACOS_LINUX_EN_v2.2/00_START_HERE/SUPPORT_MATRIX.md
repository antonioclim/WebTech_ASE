# Support matrix

| Platform | Status | Notes |
| --- | --- | --- |
| Windows 10/11 x64 | supported | Native Windows route |
| Windows 11 ARM64 | supported with matching installers | Use ARM64 packages |
| macOS Intel | supported | Use Intel packages |
| macOS Apple Silicon | supported | Use arm64 packages |
| Ubuntu/Debian x64 | supported | Native or official binary route |
| Fedora x64 | supported | Native or official binary route |
| Other Linux distributions | conditional | The preflight reports support status |
| WSL | alternative only | Not the primary Windows route |
