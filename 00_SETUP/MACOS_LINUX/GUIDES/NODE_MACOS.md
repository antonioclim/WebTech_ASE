# Install Node.js v24.21.0 on macOS

Check `uname -m` first: `arm64` means Apple Silicon and `x86_64` means Intel.
Use the matching official Node.js v24.21.0 package or an approved version manager.

Open a new terminal and verify:

```bash
node --version
npm --version
command -v node
command -v npm
```

Required result: `v24.21.0` and `11.19.0` from the same installation route.
