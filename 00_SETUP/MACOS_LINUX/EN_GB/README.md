# WebTech_ASE Day 0 environment kit

Start with [the current interactive Day 0 route](index.html). It explains what you will learn, native terminal preparation, activity-specific preparation, identifier-based recovery, the bounded S01 launch and truthful evidence. [Quick-start source](00_START_HERE/QUICK_START.md) mirrors that route.

The reference Node/npm values are retained for reproducibility, not as equality gates. Read [version and capability policy](05_CONFIGURATION/VERSION_POLICY.md). Use `ENV_OK` or `ENV_WARN` (exit 0) to continue the selected activity; `ENV_BLOCKED` (exit 2) names the requirement to repair. Node-only activities do not require npm. Editor, browser and account checks remain separate.

The supplied verifier/preflight scripts install nothing and change no persistent system settings. Following the installation guides is a separate student action requiring the actual device and institution policy. Account flags record your personal statements; they do not verify authentication or a genuine AI exchange. Readiness, package integrity, course assessment and institutional acceptance have distinct scopes. Keep failures and blockers visible.
