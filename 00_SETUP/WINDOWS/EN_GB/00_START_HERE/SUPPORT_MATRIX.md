# Intended support matrix

This table describes the configured route, not a record of testing on every native platform. Native Windows and macOS acceptance remain separate checks. Use the preflight result for your actual OS and architecture; ask the lecturer before using an alternative platform.

| Platform | Status | Notes |
| --- | --- | --- |
| Windows 10/11 x64 | planned, native execution unverified | Native Windows route |
| Windows 11 ARM64 | planned, native execution unverified | Use ARM64 packages |
| macOS Intel | planned, native execution unverified | Use Intel packages |
| macOS Apple Silicon | planned, native execution unverified | Use arm64 packages |
| Ubuntu/Debian x64 | planned, native execution unverified | Native or official binary route |
| Fedora x64 | planned, native execution unverified | Native or official binary route |
| Other Linux distributions | conditional | The preflight reports support status |
| WSL | alternative only | Not the primary Windows route |
