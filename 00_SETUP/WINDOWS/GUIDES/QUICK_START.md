# Quick start

1. Extract the complete ZIP. Do not run it from inside the archive.
2. Run the package integrity verifier.
3. Run the Day 0 preflight.
4. Read the reported remediation ID before changing anything.
5. Complete the English Day 0 form and export it to PDF for Moodle.

The target runtime is exact: Node.js `v24.21.0` and npm `11.19.0`.
