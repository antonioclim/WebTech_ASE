# Install Git and prepare GitHub

Install current Git for Windows, then configure your real identity:

```text
git config --global user.name "Given name Family name"
git config --global user.email "verified-address@example.edu"
git config --global init.defaultBranch main
```

Recommended GitHub username: `given-family-ase`. Verify the email and enable 2FA.
Do not publish passwords, tokens, cookies or Moodle data.
