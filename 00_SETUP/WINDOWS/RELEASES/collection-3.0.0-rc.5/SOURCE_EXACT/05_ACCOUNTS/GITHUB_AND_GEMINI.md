# Account checks

## GitHub

Use an identifiable account, verify the email address and enable 2FA. The preflight does not log into the account; you confirm the checks explicitly with `--ack-github` and `--ack-github-2fa`.

## Gemini

The baseline is Gemini Web. Gemini CLI, API keys and SDKs are not required. Confirm access with `--ack-gemini`.
Never upload passwords, tokens, real personal data, private databases or unauthorised private code.
