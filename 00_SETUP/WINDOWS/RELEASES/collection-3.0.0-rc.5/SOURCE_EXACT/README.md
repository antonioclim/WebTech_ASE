# WebTech_ASE environment kit

This student-facing kit checks the environment required by the Web Technologies module.
It does not install software, change persistent system settings or access GitHub or Gemini accounts.

Required Day 0 baseline:

```text
Node.js v24.21.0
npm 11.19.0
Git
VS Code Stable
Prettier and ESLint VS Code extensions
Chrome, Edge or Chromium
verified GitHub account with 2FA
Gemini Web access
```

Start with [index.html](index.html) or [00_START_HERE/QUICK_START.md](00_START_HERE/QUICK_START.md). These instructions name the verifier, preflight, form and evidence launchers for Windows. Run the integrity verifier before the preflight.

The kit reports the configured environment contract. Account acknowledgement flags are your statements; they do not verify login, 2FA or an authentic AI exchange. Intended platform support does not establish completed native-platform testing. If a required download or account is unavailable, retain the result and ask the lecturer for the permitted route.
