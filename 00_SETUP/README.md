# Day 0 environment setup

Choose the standard package for your operating system:

- [Windows](WINDOWS/README.md)
- [macOS and Linux](MACOS_LINUX/README.md)

The standard public setup packages are English-only derivatives of the locally
audited environment tools. They keep the preflight and diagnostics but exclude
Romanian guidance, teacher administration and owner-acceptance material.

## Optional one-file release candidates

Advanced one-file candidates are available under
[ALTERNATIVES](ALTERNATIVES/README.md). They are not the default route. Read the
package guide and native-acceptance boundary before using one.
