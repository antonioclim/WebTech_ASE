# LOCAL2: separate provisional classroom download

Version **3.0.0-rc.10-local.2** is a published prerelease with general qualification **NOT_FINAL**. The [frozen RC10 portal](../STUDENT_CLASSROOM_PUBLISHED_RC10/README.md) remains the default repository route. Use this separate candidate when your lecturer selects LOCAL2 for class.

## Prepare the classroom files

1. Download [WEBTECH_ASE_LOCAL2_CLASSROOM.zip](https://github.com/antonioclim/WebTech_ASE/releases/download/classroom-en-gb-v3.0.0-rc.10-local.2/WEBTECH_ASE_LOCAL2_CLASSROOM.zip) and its [SHA-256 sidecar](https://github.com/antonioclim/WebTech_ASE/releases/download/classroom-en-gb-v3.0.0-rc.10-local.2/WEBTECH_ASE_LOCAL2_CLASSROOM.zip.sha256).
2. Extract the complete ZIP into its own folder. Keep the folder structure intact.
3. Open `WEBTECH_LOCAL2/START_HERE.html` and follow the setup page for your operating system before class.
4. Use the seminar routes and runtime commands inside this extracted classroom profile. Each student completes their own required microprojects and records their own evidence.

The [static reading ZIP](https://github.com/antonioclim/WebTech_ASE/releases/download/classroom-en-gb-v3.0.0-rc.10-local.2/WEBTECH_ASE_LOCAL2_STATIC.zip) and [its sidecar](https://github.com/antonioclim/WebTech_ASE/releases/download/classroom-en-gb-v3.0.0-rc.10-local.2/WEBTECH_ASE_LOCAL2_STATIC.zip.sha256) provide a separate reading profile. Extract it independently and open `WEBTECH_LOCAL2_STATIC/START_HERE.html`. Runtime commands require the separately extracted classroom archive.

The archives labelled **Source code (zip)** and **Source code (tar.gz)** on GitHub contain development source and historical material. Download the named classroom or static attachment from [the LOCAL2 release page](https://github.com/antonioclim/WebTech_ASE/releases/tag/classroom-en-gb-v3.0.0-rc.10-local.2).
