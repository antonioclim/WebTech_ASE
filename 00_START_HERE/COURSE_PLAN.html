Course plan and required projects

Web Technologies v4.0.0 candidate. All 14 course and seminar pairs have completed their T01–T07 teaching revision with explicit limits. The latest published classroom edition remains 3.0.0. This copy is prepared for review; it is not the final stable release. Read the candidate scope.

General qualification remains NOT_FINAL. Scoped checks support their stated conclusions. Native browser rendering and saved PDF have not been executed for these candidate bytes. Read the qualification scope.

Use the course to understand the mechanisms, then use the seminar to implement and test them. The 40 microprojects listed below are all required and completed individually. Grading weights, submission windows and the actual authorised Assignment are set by your lecturer.

Teaching times remain unpiloted planning estimates. A shorter institutional slot needs an explicit continuation arrangement; it does not make a required task optional.

Open C01 · Open S01 · Detailed tutorial
