Start here

Web Technologies 3.0.0 — current repository collection. This collection contains the teaching material from the published classroom edition, arranged for use from main. Its navigation and integrity records describe this repository copy. The frozen release ZIP has its own identity.

General qualification remains NOT_FINAL. Native, manual and human acceptance is deferred by the owner; it has not passed. Read the qualification scope.

1. Obtain the complete folder

If you are viewing these files on GitHub, open the repository’s Code menu and choose Download ZIP. Extract the whole archive into a new folder and keep its structure intact. GitHub’s file view displays HTML source; use the locally extracted HTML pages for the interactive material.

Download choices explains the difference between this current repository copy and the frozen classroom release ZIP. Keep each copy in its own folder.

2. Follow your operating-system setup

  • Windows setup
  • macOS and Linux setup

The reference runtime is Node.js 24.21.0. Follow the actual unit setup instructions for its dependencies, local services and browser requirements. A static file page cannot replace a required local server, API, database or worker environment.

3. Check the supplied files

Open a terminal in the extracted collection root — the folder containing 00_SETUP, 00_TOOLS and 01_WEEKS — and run:

node 00_TOOLS/qa/VERIFY_COLLECTION.mjs

This checks the supplied files and their current collection identity. It does not complete your projects or prove that a service or browser feature works. After changing only declared learner targets or creating declared dependency/output folders, run:

node 00_TOOLS/qa/VERIFY_COLLECTION.mjs --allow-student-edits

4. Work through your week

  1. Open your course and seminar.
  2. Read the seminar start page and detailed tutorial before editing.
  3. Complete every required project individually. The starter files deliberately leave work for you.
  4. Run the task checks described by the guide and record the actual outputs.
  5. Review your evidence PDF and submit it through the Assignment specified by your lecturer.

Store private JSON drafts, evidence, logs, PDFs and your own synthetic probes outside the entire collection folder. Do not commit them to this public repository. Read the evidence guidance.
