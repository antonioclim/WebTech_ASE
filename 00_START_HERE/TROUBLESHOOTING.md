# Troubleshooting

1. Verify the setup or student kit before running it.
2. Record the exact command, exit code and smallest relevant output.
3. Confirm Node.js `v24.21.0` and npm `11.19.0`.
4. Avoid protected, read-only or deeply nested folders.
5. Do not run files directly from inside a ZIP.
6. Do not replace an expected assertion failure with a timeout or crash.

Use [SUPPORT.md](../SUPPORT.md) before opening a public issue.
