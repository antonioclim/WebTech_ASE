# Student quick start

1. Complete the Day 0 setup for your operating system.
2. Open the current week under `01_WEEKS`.
3. Choose the course or seminar.
4. For weeks 1–2, choose `RO` or `EN_GB`; for weeks 3–14, use `EN_GB`.
5. Read the wrapper README before opening `PACKAGE_EXACT` or downloading the ZIP.
6. Extract a student ZIP into a new short folder before opening `index.html` or running a project.
7. Run the package integrity verifier before running a project when the package supplies one.
8. For seminars, complete the official evidence form and upload the reviewed final PDF to the private Moodle Assignment configured by the teacher.

Weeks 03–14 are WIP previews. A checksum or readable HTML file does not qualify the application, browser, native platform, Microsoft Word or Moodle route. Do not edit files merely to make a verifier pass. Work inside the extracted student package and follow its allowed-edit contract.
