# Student quick start

1. Complete the Day 0 setup for your operating system.
2. Open the current week under `01_WEEKS`.
3. Choose the course or seminar.
4. For weeks 1–2, choose `RO` or `EN_GB`.
5. Read the wrapper README before opening `PACKAGE_EXACT`.
6. Run the package integrity verifier before running a project.
7. For seminars, complete the official experiment form and upload the final PDF to Moodle.

Do not edit files inside the repository merely to make a verifier pass. Work inside the extracted student package and follow its allowed-edit contract.
