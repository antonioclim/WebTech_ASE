Record your own work concisely and truthfully

  1. Choose one seminar route, one matching form and one PDF. Record the unit, package identity, actual environment and the exact working directory.
  2. Write your own prediction before the action. Name the input and reason; preserve the original prediction when the result differs.
  3. Record the precise change or deliberate reading action, actual command or browser action and the observed output, behaviour and exit code. Keep failures, blockers and unexecuted operations visible.
  4. Use a meaningful personal case and a potential contradiction. An expected lesson result, copied template or unexecuted command is not a witness. Record each stage's own observation and a precise evidence locator.
  5. Explain the mechanism and the limit. A finite Node or synthetic form check does not establish native browser behaviour, a saved PDF, Moodle receipt, human authorship or completion time.
  6. Retain one genuine sanitised AI critique and your independently executed check. If access is unavailable, retain BLOCKED and its reason. Keep identity, drafts, probes, logs and PDFs outside the entire collection and off the shared screen.
  7. Save and inspect the actual private JSON backup repeatedly: these forms do not autosave. Before importing, save and verify the current backup. Import replaces text/states and resets declarations; renew only truthful confirmations. A browser print request does not certify that a PDF was saved.
