# Moodle submission

Seminar submissions are individual.

```text
prediction → experiment → observed result → evidence → Gemini audit → limitation → PDF → Moodle
```

Use the official form included with the seminar package. Export one readable PDF, verify that it opens and upload it to the matching assignment on `online.ase.ro`.

Weeks 1–2 include language-specific forms inside the respective student packages. Do not upload an entire Gemini conversation, credentials or private account data.
