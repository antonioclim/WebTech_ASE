Using this student collection

Extract the full ZIP into a new writable folder under your user profile. Open index.html and complete Day 0 before running seminar commands.

The 30 selected packages are already extracted in PACKAGES. Keep the whole folder together. Do not choose an edition by sorting filenames, and do not extract a historical ZIP from a repository snapshot as a substitute.

On macOS/Linux, admitted .sh scripts are packed as executable (0755); their bytes match the selected individual ZIPs. If your extractor removes permission, run bash NAME.sh from the package folder. The unchanged original S02 ZIP uses 0644, so use bash VERIFY_PACKAGE.sh and bash OPEN_BEGINNER_GUIDE.sh when using that individual ZIP.

Read environment instructions and help, privacy and submission. Reading works offline; missing application dependencies, AI access and Moodle require the guide’s permitted continuation or your lecturer’s decision.
