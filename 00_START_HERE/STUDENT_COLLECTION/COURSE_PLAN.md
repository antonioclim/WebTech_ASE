# English course plan

This collection selects one course and one seminar object for each of 14 weeks, plus two Day 0 setup kits. Start with the Day 0 kit for your platform, then follow the course and seminar start pages for the current week. The lecturer supplies the class schedule and current institutional assessment details.

The course progresses from browser and HTTP evidence through JavaScript, server applications, data modelling, component applications, shared state, security and real-time behaviour. Each package states its own objectives, prerequisites, required project and optional extensions. Use those explicit roles: an optional extension is not automatically required because it is present in the collection.

Before class, complete the package preparation and provision dependencies. During a timed seminar, follow its investigation and assessed edit boundary. Afterwards, organise the required evidence, distinguish observed results from expected outcomes, and follow the submission guide. A short handout is a synthesis sheet; use the accompanying course reading for the fuller explanation.

For personal planning, allow preparation and follow-up time outside the class session. Any repository timing is an estimate until tested with students; it is not evidence that every beginner can complete the work in the stated time. If a required step exceeds the session or is blocked by the environment, preserve progress and request the lecturer's continuation route.

Evidence should connect a claim to a reproducible observation and its limitation. Retain baseline, objective and regression outputs separately. An incomplete objective can be a valid starter state. Neither an exact package hash nor a generated form grants a mark, authenticates an AI exchange or proves submission acceptance.
