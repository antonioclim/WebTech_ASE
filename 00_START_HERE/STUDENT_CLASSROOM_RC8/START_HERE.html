Start the filtered classroom collection

This is a classroom prerelease. It supplies the current course material and bounded individual seminar route. It is not a certificate of completed student work, full application support or institutional acceptance.

  1. Extract the entire ZIP to a normal local folder. Open index.html from the extracted folder. Do not run a file directly inside the ZIP viewer.
  2. Follow the appropriate setup entry on the collection home page. The reference runtime is Node.js 24.21.0. Check node --version in your terminal.
  3. Open a terminal in the extracted collection root. Run node VERIFY_COLLECTION.mjs. A clean initial copy reports PASS_INITIAL_BYTES_ONLY. A STOP result needs correction before class.
  4. Choose the current week's course and seminar from the home page. For the seminar, open its new entry page and follow the classroom start and guide. Complete all two or three listed microprojects individually.
  5. Edit only the target files identified by the seminar guide. Keep tests, protected support files and the evidence form intact. Record actual commands and actual outcomes.
  6. After editing or installing dependencies, run node VERIFY_COLLECTION.mjs --allow-student-edits to check protected files. This mode permits only 38 declared editable files and excludes declared dependency/build/evidence folders. It does not test the contents of those excluded folders or award a grade. Use the seminar's separate project checks to assess your implementation.
  7. Use the current classroom evidence form. Copy the filtered seminar PACKAGE_ID.txt shown on its entry page. The SOURCE_PACKAGE_ID.txt is the original full-package provenance and is not the filtered seminar identity.
  8. Print one PDF for that seminar, reopen the saved PDF and inspect every page. Keep private evidence in your own folder or STUDENT_EVIDENCE. Submit it only to the assignment authorised by your lecturer. Do not submit synthetic examples or invent a PASS for unavailable work.
