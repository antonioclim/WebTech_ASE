What is created and what remains unverified

The probes use only owned temporary files, an in-memory database, an ephemeral loopback listener and bounded child processes. They close and remove their own resources. Tool diagnostics allow 5 seconds and 64 KiB; native Day 0 diagnostics allow 10 seconds, with Windows editor probes at 15/20 seconds. HTTP has one 4-second attempt. A timeout or real failed exit is a blocked check, even if a version number looks close to the reference.

Windows/macOS native execution, browser rendering, account access, React companions and completion time remain unverified by these probes. No version injection or policy test certifies a runtime. The common policy is integrated into C01, C03–C06, S01–S06 and Day 0. The C02 browser activity has its own source and native observation requirements.
