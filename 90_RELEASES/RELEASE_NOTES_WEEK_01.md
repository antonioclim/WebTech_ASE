# Week 1 v2.0.0

This final release contains the complete C01 and S01 student packages in Romanian
and British English. It includes the evidence-oriented seminar workflow, the
Gemini audit activity, Moodle-ready evidence forms and exact package checksums.

The release assets are immutable. A correction receives a new patch version and
new asset filenames; an existing tag or release must never be silently replaced.
