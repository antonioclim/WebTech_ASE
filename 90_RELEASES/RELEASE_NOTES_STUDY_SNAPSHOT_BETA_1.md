## Beta study snapshot — please read before downloading

This is the first whole-repository study snapshot in this GitHub release series. It preserves the source at commit `6e5cc0a917429d7120f71fd153e8853f05729c9d` and includes the Week 01–02 English remediation merged in PR #16. It is a **beta pre-release**: the complete fourteen-week repository remains work in progress.

The materials may be used for guided study while the next edition is being developed on the `next-release` branch. Follow the requirements and instructions for the selected activity. This snapshot is not a claim that every exercise, platform or classroom workflow has been validated.

### Choose the appropriate download

- **For the reviewed English Week 01–02 route**, use `WEBTECH_ASE_WEEKS_01_02_EN_GB_v2.1.0-rc.1.zip` and its SHA-256 sidecar. It contains the filtered C01, S01, C02 and S02 student packages. Its identity is **2.1.0-rc.1**, independently of this whole-source snapshot label.
- GitHub's **Source code** archives contain the full tracked source snapshot, including material outside that reviewed route. They are not filtered student distributions and do not include Git history.

### Verification and remaining limitations

The current audit and local remediation cover **Weeks 01–02 EN only**. They do not qualify Weeks 03–14 or the Romanian packages. Native Windows and macOS operation, manual browser interaction, Microsoft Word rendering, the live Moodle upload and review workflow, a beginner pilot and owner acceptance remain pending. A local check passing does not complete these gates; publishing this beta does not complete owner acceptance of the final edition.

Some seminar starters are intentionally incomplete. Follow their initial-state verification and allowed-edit instructions; completing an exercise is a separate step. Previously exposed S01 solution material remains in Git history, so automated results alone are insufficient evidence of individual understanding.

The repository's existing citation and frozen baseline identity remain **2.0.1**. Its repository checksum receipts describe that baseline, not the changing work-in-progress tree or this whole-source beta. Use the pinned source commit for provenance and the separate student archive checksum for that download.

Future reviewed changes will receive a new release identity. This snapshot's tag and downloadable assets should be preserved rather than replaced. Subsequent release notes will declare the scope, tested environments and known limitations of that edition.
