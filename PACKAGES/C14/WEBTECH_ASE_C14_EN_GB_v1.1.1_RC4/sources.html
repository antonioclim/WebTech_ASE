Primary basis

The basis is exact Unit 14, the 38 numbered lecture topics, five canonical examples and the approved Week 14 architecture. Public hashes are in CANONICAL_SOURCES.json.

Corrections retained

  1. The API example verifies the create response, not a later persistence read.
  2. The seeded-defect example does not await cleanup through a guaranteed finally boundary.
  3. The latency example stops at response availability rather than consuming the body.
  4. The log example retains raw path and a caller-provided request ID.
  5. The tri-state example accepts truthy TLS evidence and runs commands without a bounded timeout.
  6. Historical full-application context; implementation is optional advanced reference, outside the current seminar task allocation. Current S14 task list and evidence route. P02 is optional advanced and P04 is a separate assessment-bank task.
