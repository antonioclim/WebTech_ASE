Before the meeting: prepare reasoning, not a live installation

Open index.html from the extracted course package. Check that the title identifies C05 v1.1.0. Open the presentation and the laboratory. Both work directly from files and do not require Express. Set a comfortable text size in the presentation; 40–160% is available independently of browser zoom. Read handout sections 1–3. Prepare one prediction for a creation request: method, path, request media type, response status, Location and body envelope. Separately predict which handler owns a static page and which owns an API path in canonical example 01. You are preparing a model, not collecting a retrospective answer. Application execution has a different prerequisite. The five exact examples keep their package files and lockfiles. The optional guide explains how an already authorised, project-local environment is prepared in a work copy. Do not install dependencies during the live teaching hour, use a global Express installation or edit the lock. If a prerequisite is absent, record the block and continue with labelled source/model reasoning until execution is available.

Keep the extracted folder, a plain-text note document and the course laboratory available. No account or secret is needed for the offline shell. Gemini access belongs to a later bounded review; the synthetic practice claim is available without pretending a real conversation occurred.
