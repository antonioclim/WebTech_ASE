# C08 — Launch and use guide

## 1. Extract the complete package

On Windows, save the student ZIP, right-click it and use Extract All into a new, short folder, for example D:\WTW08C. Open that folder in File Explorer and double-click index.html. On macOS, expand the ZIP in Finder and open index.html in the extracted folder. On Linux, use the graphical archive manager to extract into a new folder and open index.html with a browser. Preserve every relative folder; do not move lab.html away from assets.

The ordinary lesson route does not use a terminal, server, account, React installation or CDN. Keep teacher/private archives separate. This guide is for local teaching use, not GitHub publication.

## 2. Navigate and read

Open the lesson. Use Previous, Next or the Screen selector. ArrowRight/PageDown and ArrowLeft/PageUp navigate; Home and End go to the endpoints. Shortcuts deliberately do nothing while typing in inputs, text areas or contenteditable regions and do not hijack links, buttons, selects or summary controls. Modifier shortcuts remain available to the browser.

Use Text to choose 40–160%. Content remains in normal document flow; scroll when needed instead of expecting a fixed-height screen to hide overflow. Reading mode shows every screen. Print all applies the print layout to all screens. Inspect your local print preview and the saved output before claiming a PDF exists. No browser or Word-native acceptance is inferred from the production QA.

The final screen is the planned minute-60 stop. Its presence does not prove elapsed time. The remaining 30 minutes are not a buffer.
