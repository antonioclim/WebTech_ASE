SOURCE:05 — cooperative cancellation, not a latest-only guard

The actual main.jsx creates an AbortController and passes its signal to a timer-based loader. The loader clears its timer and rejects AbortError when aborted. It does not deliberately settle after cancellation. The effect has no monotonic request identity. The stronger claims in its original README are not supported by this implementation. The separate lab has named non-cooperative models and must not be described as this original Vite application.

SOURCE:03 and SOURCE:04 — event-owned ID fragments

It is an explanatory fragment, not an automatically applied patch, a complete S08 answer or a claim that duplicated rows were observed.
