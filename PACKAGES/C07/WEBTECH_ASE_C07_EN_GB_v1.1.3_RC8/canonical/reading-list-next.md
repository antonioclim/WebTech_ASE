# Reading list for the next lecture — Lecture 08 — React with Vite

Complete these readings before Lecture 08 — React with Vite.

- [React: Describing the UI](https://react.dev/learn/describing-the-ui) — learn components, JSX, props, conditions, and list rendering.
- [React: Adding interactivity](https://react.dev/learn/adding-interactivity) — connect events and state to render transitions.
- [React: Updating objects in state](https://react.dev/learn/updating-objects-in-state) — preserve state identity rules through immutable updates.
- [React: Synchronizing with effects](https://react.dev/learn/synchronizing-with-effects) — use effects for external synchronization and reason about cleanup.
