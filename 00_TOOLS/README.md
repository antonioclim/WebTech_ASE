# Repository tools

- `qa/validate_public_repo.py`: validates structure, language policy, public/private boundary, ZIPs, sidecars, links and exact package copies.
- `publishing/build_week_bundle.py`: builds one-language weekly bundles from two student ZIPs.
- `maintainer/`: English-only maintenance guidance for the local repository snapshot.

These tools do not publish to GitHub and do not access student accounts.
