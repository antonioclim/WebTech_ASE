## Controls

Strict validation covers the whole current source; no week filter weakens it. Each selected archive has a mandatory sidecar, exact projection, verified authentic identity and explicit start/guide/form paths. Fixed code policies retain five identity recipes and each package's real editable boundary. ZIP metadata and budgets are checked before CRC expansion, including directories, namespace collisions and nested OOXML scans. YAML uses a duplicate-aware parser and exact locked action references; both YAML extensions are discovered. JSON duplicates and nonstandard numeric values are rejected.

The filtered Pages payload is compared as an exact file and byte inventory. Local URLs are decoded before containment checks; absolute application assets cannot escape their own app root. This checks static assets, not live server routes. Language evidence binds purpose dispositions to every text file; it is not a human fluency certificate. Credential-pattern scans have finite coverage. Unsigned manifests establish consistency, not publisher authentication.

Atomic creation applies to individual files and identical-byte replay. Publication of a directory is staged, but concurrent directory builders are unsupported; there is no claim of a multi-output transaction. Different existing outputs and symlink paths are refused. Workflow output is accepted only in the explicitly requested, precreated empty regular file shape from GITHUB_OUTPUT with GITHUB_ACTIONS=true. Local simulated tests do not constitute an Actions run.

## Qualification

Ten gates remain fixed in code: local integrity, reference runtime, headless browser, native Windows, native macOS, manual browser, Word, live Moodle, human pilot and owner acceptance. Final qualification requires current source and registry bindings, every selected object, named observers and roles, versioned platforms, timezone-aware nonfuture observations, described checks and retained evidence hashes. This is observer-asserted evidence, not cryptographic proof that a human performed an experiment. The candidate plan never silently becomes final.

Windows evidence on main covers the four exact RC2 packages; it is preserved without transferring it to this new collection. Workload, compulsory versus optional project scope, grading descriptors, AI policy, Moodle configuration and final institutional decisions require the lecturer. Recovered forms and progressive guidance do not prove that all projects fit into a 60-minute class.
