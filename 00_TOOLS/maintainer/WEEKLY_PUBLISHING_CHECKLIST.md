# Weekly publishing checklist

1. Confirm the student package is release-ready.
2. Confirm language policy and Moodle workflow.
3. Copy the ZIP and sidecar into `DOWNLOAD`.
4. Extract the exact ZIP into `PACKAGE_EXACT` without editing it.
5. Update the language README and week README.
6. Update `90_RELEASES` indexes.
7. Run the strict validator.
8. Never upload teacher staging to the public repository.
