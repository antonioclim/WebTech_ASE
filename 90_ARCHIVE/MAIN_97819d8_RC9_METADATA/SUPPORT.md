# Support

Before reporting a problem:

1. verify the downloaded kit;
2. record the object code and version;
3. record the operating system, Node and npm versions;
4. reproduce the smallest failing command;
5. remove credentials and private data.

Use the technical-problem issue form for software failures and the content-correction form for wording or factual issues. Moodle deadlines and grading decisions are handled in the official course channel, not through GitHub issues.
