# Windows setup

1. Download [WebTech_ASE_ENVIRONMENT_WINDOWS_EN_v2.2.zip](DOWNLOAD/WebTech_ASE_ENVIRONMENT_WINDOWS_EN_v2.2.zip).
2. Verify the SHA-256 sidecar.
3. Extract the complete ZIP.
4. Run the integrity verifier.
5. Run the Day 0 preflight.
6. Complete the English Day 0 form and upload the PDF to Moodle.

The exact extracted package is available under `PACKAGE_EXACT` for browsing. Do not edit it in the repository.
